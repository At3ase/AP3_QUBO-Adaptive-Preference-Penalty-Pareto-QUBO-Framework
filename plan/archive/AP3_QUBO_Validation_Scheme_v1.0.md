## 一、可行性筛检：实验优先级重排

在挑战杯2个月周期、无材料熔炼资源、仅有玻色量子 kaiwu SDK 的现实约束下，需要对原有5组实验进行可行性筛检与优先级重排。核心原则：**纯软件实验优先，物理验证通过替代方案降级实现**。

### 1.1 五组实验可行性评估

| 实验 | 原方案建议 | 现实可行性 | 调整策略 |
|------|-----------|-----------|---------|
| 实验1：PrecisionSplit验证 | 编码效率对比 | **高**——纯软件，1-2天 | 保留，直接对比38 vs 48变量 |
| 实验2：PenaltyFlex验证 | 约束满足率、收敛速度 | **高**——纯软件，2-3天 | 保留，核心创新必须验证 |
| 实验3：ParetoZoom验证 | Hypervolume提升 | **高**——纯软件，3-5天 | 保留，国赛级关键数据 |
| 实验4：γ敏感性分析 | Pareto前沿变化 | **高**——纯软件，1-2天 | 保留，证明方案稳定性 |
| 实验5：CALPHAD验证 | Thermo-Calc/Pandat对比 | **中低**——商业软件许可贵 | 替代方案见1.2节 |

### 1.2 实验5替代方案设计

原方案使用Thermo-Calc或Pandat商业软件进行CALPHAD验证，存在许可证昂贵、学习曲线陡峭的问题。设计**三级替代方案**，按可获得性灵活选择：

| 级别 | 方案 | 资源需求 | 说服力 | 推荐度 |
|------|------|---------|--------|--------|
| **A（最优）** | Pycalphad开源CALPHAD + 公开数据库 | 免费，Python环境 | ★★★★ | **首选** |
| **B（备选）** | 文献回测：已发表实验数据对比 | 文献检索能力 | ★★★ | 与A并行 |
| **C（保底）** | 物理后处理过滤器内部一致性验证 | 零额外资源 | ★★ | 必做 |

**建议执行组合**：A + B并行。Pycalphad是纯Python的CALPHAD引擎，安装简单（`pip install pycalphad`），支持公开热力学数据库，可在2周内完成部署与验证。文献回测则通过对比已发表AlCoCrFeNi-C体系的实验相图数据，验证AP³预测成分的物理合理性。

### 2.1 PrecisionSplit 编码效率验证（实验1）

**实验目的**：证明分层精度编码相比统一编码，在变量数减少20%的前提下性能无显著损失。

#### 对照组与实验组设计

| 参数 | Baseline（统一编码） | AP³（PrecisionSplit） |
|------|---------------------|----------------------|
| 变量数 | 6元素 x 8bit = 48变量 | 主元5x7bit + C 3bit = 38变量 |
| 步长 | 0.25% | 0.25%（与统一编码一致，确保公平） |
| 覆盖范围 | 5%~68.75%（远超需求） | 主元5%~36.75%，C 0%~1.75% |
| 等原子比兼容性 | 兼容 | 兼容（K=300精确可达） |

#### 评价指标

| 指标 | 符号 | 计算方式 | 期望结果 |
|------|------|---------|---------|
| 变量压缩率 | CR | (48-38)/48 x 100% | **20.8%** |
| QUBO矩阵非零项 | nnz | 矩阵统计 | AP³显著减少 |
| 单次求解时间 | T_solve | 平均10次求解 | AP³ <= Baseline的1.2倍 |
| 最优目标值偏差 | Δf* | |f*_AP³ - f*_Base| / |f*_Base| | < 2%（性能无损失） |
| 可行解率 | FR | 满足约束解 / 总解 | AP³ >= Baseline |

**关键图**：柱状图对比五维指标（N / nnz / T_solve / Δf* / FR），四子图并列展示。

### 2.2 PenaltyFlex 自适应惩罚验证（实验2）

**实验目的**：证明PenaltyFlex相比固定惩罚系数，收敛更快、可行解率更高、最终解质量更好。这是**最重要**的实验，直接验证方案的核心创新之一。

#### 对照组设计

| 配置 | λ设置 | 说明 |
|------|-------|------|
| Baseline-1 | 固定 λ = 1 | 低惩罚，约束松散 |
| Baseline-2 | 固定 λ = 10 | 中等惩罚 |
| Baseline-3 | 固定 λ = 100 | 高惩罚，约束严格 |
| AP³ | PenaltyFlex自适应 | λ_sum=15固定，λ_carbide/λ_CCr自适应 |

每个配置运行12组粗网格权重，记录完整收敛历史。

#### 评价指标

| 指标 | 符号 | 物理意义 | 期望结果 |
|------|------|---------|---------|
| 约束满足率 | FR | 解的可行性比例 | AP³ > 固定λ 10%以上 |
| 最佳目标值 | f*_best | 解的质量上限 | AP³ >= 最优固定λ |
| 收敛迭代数 | CI | 达到95%最终性能所需轮数 | AP³减少30%以上 |
| λ振荡次数 | N_osc | 稳定性度量 | AP³ < 固定λ调参次数 |
| 超参数敏感度 | σ | 多次运行f*的标准差 | AP³ < 固定λ |

### 2.3 ParetoZoom 前沿质量验证（实验3）

**实验目的**：证明ParetoZoom相比均匀权重扫描，能获得更高质量的Pareto前沿。这是**国赛级别最重要**的数据，直接体现多目标优化能力。

#### 对照组设计

| 参数 | Baseline（均匀网格） | AP³（ParetoZoom） |
|------|---------------------|------------------|
| 权重扫描策略 | 50组权重均匀分布在单纯形上 | 粗网格12组 + 动态加密 |

| **Pareto点数量** | |P| | 非支配解数量 | AP³多30%以上 |

参考点设置：r = (max f_i + 10%xrange, max f_i + 10%xrange, max f_i + 10%xrange)，确保HV > 0。

### 2.5 物理合理性验证（实验5）

**A方案：Pycalphad开源验证（首选）**

```python
# 示例流程
from pycalphad import Database, equilibrium
import numpy as np

# 加载公开数据库
dbf = Database('alcocrfeni-c.tdb')

# 选取AP³ Top20解中的5个代表性成分
compositions = [
    {'AL': 0.20, 'CO': 0.20, 'CR': 0.20, 'FE': 0.20, 'NI': 0.19, 'C': 0.01},
    # ... 更多成分
]

# 计算平衡相组成（目标温度如1000°C）
for comp in compositions:
    eq = equilibrium(dbf, ['AL', 'CO', 'CR', 'FE', 'NI', 'C', 'VA'],
                     ['FCC_A1', 'BCC_A2', 'M23C6', 'LIQUID'],
                     comp, T=1273, P=101325)
    print(eq.Phase)
```

**验证内容**：

| AP³预测 | Pycalphad验证 | 一致？ |
|---------|--------------|--------|
| f₁低（热力学稳定） | 主要相为FCC/BCC固溶体 | ✅ 应一致 |
| c_C > 0.8%（P1违反） | 出现M₂₃C₆/M₇C₃碳化物 | ✅ 应一致 |
| Ω > 1.1（后处理通过） | 无金属间化合物 | ✅ 应一致 |

**B方案（并行）**：文献回测。选取已发表文献中的AlCoCrFeNi-C实验数据，对比AP³预测成分与文献实测相组成，计算一致率：

```
CAR = N_agreement / N_total x 100%
目标：CAR >= 80%
```

**关键图**：表格展示AP³预测 vs CALPHAD/文献验证对比；柱状图统计一致率。

## 三、量化创新贡献指标体系

定义6个核心指标，用于在挑战杯答辩中**一句话证明创新**：

| 创新点 | 指标 | 计算公式 | 目标值 |
|--------|------|---------|--------|
| PrecisionSplit | 变量压缩率（CR） | (48-38)/48 x 100% | **20.8%** |
| PrecisionSplit | 性能保持率（PR） | 1 - |Δf*|/|f*| | **> 98%** |
| PenaltyFlex | 收敛加速比（SR） | CI_fixed / CI_AP³ | **> 1.3x** |
| PenaltyFlex | 可行解率提升（FR+） | FR_AP³ - FR_fixed | **> 10%** |
| ParetoZoom | Hypervolume提升（HV+） | (HV_AP³-HV_base)/HV_base | **> 10%** |
| ParetoZoom | 前沿点密度提升（PD+） | (|P_AP³|-|P_base|)/|P_base| | **> 30%** |

**指标选取逻辑**：
- **变量压缩率（CR）**：最直接证明PrecisionSplit编码效率，20.8%的压缩率在量子计算资源有限场景下意义重大
- **性能保持率（PR）**：证明压缩变量不以牺牲解质量为代价
- **收敛加速比（SR）**：PenaltyFlex核心价值——更快找到高质量可行解
- **可行解率提升（FR+）**：PenaltyFlex直接效果——更多解满足物理约束
- **Hypervolume提升（HV+）**：ParetoZoom核心竞争力——多目标优化的国际通用度量
- **前沿点密度提升（PD+）**：ParetoZoom覆盖能力——更多非支配解=更丰富的设计选择
