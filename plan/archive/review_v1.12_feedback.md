### [N2] PenaltyFlex 振荡检测在 t=2 时存在 sign(0) 边界情况（LOW）

**位置**：§3.2.5 算法伪代码，行 332

**问题**：

```
行 332：IF t > 1 AND sign(λ_j⁽ᵗ⁾ − λ_j⁽ᵗ⁻¹⁾) ≠ sign(λ_j⁽ᵗ⁻¹⁾ − λ_j⁽ᵗ⁻²⁾):
```

当 t=2 时：
- `λ_j⁽²⁾ − λ_j⁽¹⁾` = (0.05 + α_add·v̄_j) − 0.05 = **正值** → sign = +1
- `λ_j⁽¹⁾ − λ_j⁽⁰⁾` = 0.05 − 0.05 = **0** → sign = **0**

若实现中 `sign(+1) ≠ sign(0)` 评估为 True（多数语言下 `1 ≠ 0` 为 True），则 t=2 时会误触发几何平均步骤 `λ = √(λ⁽²⁾·λ⁽¹⁾)` 替代预期的加性启动步骤。

**影响分析**：实际影响极小。几何平均 `√((0.05+Δ)×0.05)` 与加性 `0.05 + Δ` 在数值上接近，且 λ 仍会增长。但从算法逻辑正确性角度，加性阶段应优先于振荡检测。

**修复建议**：在条件中增加 `λ_j⁽ᵗ⁻¹⁾ ≠ λ_j⁽ᵗ⁻²⁾` 的保护：
```
IF t > 1 AND λ_j⁽ᵗ⁻¹⁾ ≠ λ_j⁽ᵗ⁻²⁾ 
   AND sign(λ_j⁽ᵗ⁾ − λ_j⁽ᵗ⁻¹⁾) ≠ sign(λ_j⁽ᵗ⁻¹⁾ − λ_j⁽ᵗ⁻²⁾):
```
或将加性阶段判断前置（ELIF 优先于振荡检测）。

**严重性**：低。不影响正确性，仅影响 t=2 时的算法分支选择。

### [N3] CONVEXITY_TEST_3D 伪代码未指定各投影面的排序轴（LOW）

**位置**：§4.2.2，行 524-533

**问题**：

3D 凸性检验对三个投影平面均执行，但伪代码未指定每个平面的横轴（用于排序"相邻"非支配解）：
- `(f₁, f₂)` 平面：应排序 by f₁
- `(f₁, f₃)` 平面：应排序 by f₁
- `(f₂, f₃)` 平面：应排序 by f₂

此外，`|P₀|_proj`（该投影面上的非支配解数量）可能与完整 3D 存档 `|P₀|` 不同——在 2D 投影中，原来被 3D 支配的解可能变为非支配。伪代码中 `ratio ← count / |P₀|_proj` 的分母需注意这一点。

**修复建议**：在伪代码中显式标注排序轴和分母计算方式。

**严重性**：低。实现时可自然处理，不影响算法正确性方向。

### [N4] P2 约束"违反度"定义在 PenaltyFlex 中不够明确（LOW）

**位置**：§3.2.5 行 327 `v_k = 约束违反度`

**问题**：

PenaltyFlex 第 4 步 `TOP-10解解码：{(c_k, v_k)}，v_k = 约束违反度`。对于 P2（C-Cr 耦合最小化），"约束违反度"需要明确的量化定义。H_CCr 归一化到 [0,1] 范围，最大值为 ~0.64（当 c_C=1.75, c_Cr=36.75 时）。但 `v̄_j` 直接用于加性更新 `λ += α_add·v̄_j`，若 v̄_j 的量级不合适，可能影响 λ 的增长速度。

**建议**：在实现时统一 `v_j` 定义：
- P1 违反度：`v_carbide = (c_C − 0.8)²`（自然单位 %²，范围 [0, 0.90]）
- P2 违反度：`v_CCr = H_CCr = c_C × c_Cr / 64.3125`（归一化值，范围 [0, 1]）

当前参数 `α_add = 0.5` 对两种量级均在合理范围内（P1 的 λ 增长约 0~0.45/轮，P2 增长约 0~0.5/轮）。

**严重性**：低。参数设置合理，标注即可。
