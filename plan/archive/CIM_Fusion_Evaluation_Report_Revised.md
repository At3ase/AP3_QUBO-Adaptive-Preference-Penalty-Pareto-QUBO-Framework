## 二、真机额度有限下的最优分配策略

### 2.1 核心原则：真机只用于"不可模拟"或"展示价值最高"的场景

| 场景类型 | 是否需真机 | 理由 | 建议额度分配 |
|---------|-----------|------|-------------|
| **消融实验（实验0）** | ❌ 模拟器即可 | 消融实验的核心是算法逻辑验证，模拟器与真机行为一致即可 | 0次 |
| **编码效率对比（实验1）** | ❌ 模拟器即可 | PrecisionSplit vs 统一编码是确定性编码方案对比，与量子硬件无关 | 0次 |
| **PenaltyFlex自适应（实验2）** | ⚠️ 部分需真机 | 自适应逻辑在模拟器上验证；仅需1-2组代表性权重在真机上做"最终验证" | 2-3次完整pipeline |
| **ParetoZoom前沿（实验3）** | ✅ 真机必需 | 这是"量子vs经典"对比的核心展示场景，真机数据是答辩亮点 | 1-2次完整pipeline |
| **γ敏感性（实验4）** | ❌ 模拟器即可 | 敏感性分析是参数扫描，模拟器足够 | 0次 |
| **物理验证（实验5）** | ❌ 不涉及量子 | Pycalphad是纯经典计算 | 0次 |
| **真机-模拟器一致性检验** | ✅ 真机必需 | 验证模拟器结果在真机上可复现，是"真机使用"的合理性前提 | 1次标准QUBO × 10次重复 |

### 2.2 建议的真机额度分配方案（保守估计：≤50次真机提交）

```
总预算：~50次真机QUBO提交（含重复）

分配方案：
├── 阶段A：真机-模拟器一致性检验（10次）
│   └── 1个标准QUBO（等原子比权重w=(0.33,0.33,0.33)）
│   └── 每次num_reads=1000，共10次独立提交
│   └── 目的：验证模拟器最优解在真机上的复现率
│
├── 阶段B：PenaltyFlex最终验证（15次）
│   └── 选择1组代表性权重（如w=(0.5,0.35,0.15)校准权重）
│   └── 模拟器上跑完整PenaltyFlex获取λ*，真机上用λ*直接求解
│   └── 3次重复 × 5轮ParetoZoom迭代 = 15次
│   └── 目的：证明自适应惩罚在真机上有效
│
├── 阶段C：ParetoZoom最终前沿（20次）
│   └── 选择2组对比权重（如w=(0.7,0.2,0.1)和w=(0.2,0.7,0.1)）
│   └── 每组完整pipeline（粗网格12组 + ParetoZoom 2-3轮）
│   └── 每组~10次真机提交 × 2组 = 20次
│   └── 目的：生成真机Pareto前沿，用于与NSGA-II的"媲美"对比
│
└── 阶段D：精度边界探测（5次）
    └── 构造"真机友好版"QUBO（见§三.2）与"原始版"QUBO的对比实验
    └── 5次提交 × 2版本 = 10次（可与阶段A合并）
    └── 目的：验证精度截断对解质量的影响可忽略
```

**总计：~50次真机提交**，远低于原方案的600~900次，且集中在"展示价值最高"的区域。

## 三、精度问题：从"过于精细"到"真机友好"的技术路径

### 3.1 问题诊断：哪些系数对CIM过于精细？

| 系数来源 | 原始值 | 乘以ω·λ后量级 | CIM可分辨性 | 影响 |
|---------|--------|--------------|------------|------|
| P0硬约束（成分和） | λ_sum/5625 × coef | ~0.01~0.1 | ✅ 可分辨 | 核心约束，必须保留 |
| f₁（ΔH_mix）交叉项 | 4×ΔH_ij×0.25² | ~0.25~6.1 | ✅ 可分辨 | 目标函数主体，必须保留 |
| f₂（密度）线性项 | ρ_i×0.25 | ~0.5~2.2 | ✅ 可分辨 | 线性项，直接映射h_i |
| f₃（成本）线性项 | w_k×0.25 | ~0.5~25 | ✅ 可分辨 | 线性项，直接映射h_i |
| **P2（C-Cr耦合）交叉项** | **0.000972 × 2^(k+j)** | **~0.001~0.25** | ❌ **不可分辨** | **需重新设计** |
| P2（C-Cr耦合）线性项 | 0.01944 × 2^k | ~0.02~0.08 | ⚠️ 边界 | 可能可分辨，但接近噪声floor |

**结论**：P2约束的交叉项是唯一的"真机不可分辨"区域。P2的线性项处于边界，需实验验证。

### 3.2 解决方案：P2约束的"真机友好化" redesign

#### 方案A：P2截断法（推荐）

**核心思想**：将P2的交叉项系数低于阈值的部分截断为0，仅保留可分辨的较大系数。

```python
# 真机友好版P2注入逻辑
threshold = 0.01  # CIM可分辨的最小系数（需实验标定）
base = 0.000972 * omega_CCr * lambda_CCr

for k in range(3):       # C: x_35, x_36, x_37
    for j in range(7):   # Cr: x_14, ..., x_20
        coeff = base * (2**k) * (2**j)
        if coeff >= threshold:   # 仅注入可分辨的系数
            Q[35+k][14+j] += coeff
        else:
            # 截断为0，不注入
            pass
```

**截断后的影响分析**：

| 截断阈值 | 保留的交叉项数 | 最大保留系数 | 对P2约束强度的影响 |
|---------|--------------|------------|------------------|
| 0.001 | 21/21（全部） | 0.24879 | 无影响 |
| 0.01 | 15/21 | 0.24879 | 损失6个最小项，影响<5% |
| 0.05 | 9/21 | 0.24879 | 损失12个中小项，影响~15% |
| 0.1 | 6/21 | 0.24879 | 损失15个小项，影响~25% |

**推荐策略**：
1. 先用模拟器对比"完整P2" vs "截断P2（threshold=0.01）"的Pareto前沿差异
2. 若差异<5%（预期），则采用threshold=0.01的真机版本
3. 若差异>10%，则改用方案B

#### 方案B：P2线性化替代（备选）

**核心思想**：放弃P2的交叉项，仅用线性项近似P2约束。

```python
# 线性化P2：仅保留h_i偏置场，Q矩阵不注入C-Cr交叉项
h[35] += omega_CCr * lambda_CCr * 0.01944  # C,b0
h[36] += omega_CCr * lambda_CCr * 0.03887  # C,b1
h[37] += omega_CCr * lambda_CCr * 0.07775  # C,b2
# Q矩阵中P2区域全部置0
```

**物理含义变化**：
- 原始P2：`H_CCr = c_C × c_Cr / H_max` —— 抑制C与Cr的协同效应
- 线性化P2：`H_CCr ≈ c_C × E[c_Cr] / H_max` —— 仅抑制C的绝对含量（与P1部分重叠）

**代价**：线性化P2失去了"高Cr时更严格抑制C"的协同特性，退化为P1的弱化版。

**适用条件**：若方案A的截断实验显示即使threshold=0.01也导致显著性能损失，则改用方案B，并调整叙事为"P1+P2合并为单一碳化物抑制约束"。

#### 方案C：P2系数放大法（备选）

**核心思想**：不截断P2，而是整体放大P2的系数使其超出CIM噪声floor。

```python
# 放大P2的归一化分母，使系数整体增大
H_max_new = 6.43125  # 原H_max=64.3125的1/10
# 或：直接放大omega_CCr
omega_CCr_real = 5.0  # 真机上使用放大后的权重
```

**代价**：P2的相对强度被人为放大，可能过度抑制C-Cr耦合，导致Pareto前沿向低C区域偏移。

**适用条件**：若P2的物理意义对答辩叙事至关重要（如"我们同时抑制了C的绝对含量和C-Cr协同效应"），则采用此方案，并在文档中明确说明"真机版本对P2进行了系数放大以适配硬件精度"。

### 3.3 推荐决策树

```
模拟器实验：
├── 对比"完整P2" vs "截断P2(threshold=0.01)" vs "线性化P2"
│   └── 若截断P2的HV损失 < 5%：
│       └── ✅ 采用方案A（截断法）作为真机版本
│   └── 若截断P2的HV损失 5%~15%：
│       └── ⚠️ 采用方案A，但降低P2的叙事权重（从"核心创新"降为"辅助约束"）
│   └── 若截断P2的HV损失 > 15%：
│       └── 对比"线性化P2" vs "放大P2"
│           └── 若线性化P2可接受：采用方案B
│           └── 否则：采用方案C，并在文档中声明系数放大
```

## 四、经典对比策略：从"超越"到"媲美"的叙事重构

### 4.1 原方案（v1.1）的经典对比压力

| 原目标 | 压力来源 | 修订后目标 |
|--------|---------|-----------|
| HV_ratio > 1.10（量子超越经典10%） | 需要量子显著优于NSGA-II | **HV_ratio ≥ 0.90**（量子达到经典的90%即可） |
| C(AP³, NSGA-II) > 0.40 | 需要量子前沿支配大量经典解 | **C(AP³, NSGA-II) ≥ 0.20**（量子前沿至少覆盖20%经典解） |
| "量子方法在同等求解预算下不劣于经典" | 需要严格统计证明 | **"量子方法在同等求解预算下达到经典方法的同等数量级"** |

### 4.2 "媲美"叙事的实验设计调整

#### 实验3（ParetoZoom vs NSGA-II）的简化版

| 维度 | 原设计（v1.1） | 修订设计（"媲美"版） |
|------|---------------|-------------------|
| 对比方法 | NSGA-II + Random Search | **仅NSGA-II**（去掉Random Search，降低实验量） |
| 评估指标 | HV + C-metric + Spread + \|P\| + T_wall | **HV + C-metric**（仅保留2个核心指标） |
| 统计要求 | ≥20次重复，Mann-Whitney U，Cohen's d | **≥10次重复**（降低真机压力），报告均值±SD即可 |
| 成功标准 | HV_ratio > 1.10，p < 0.01 | **HV_ratio ∈ [0.85, 1.15]**，即"在同一数量级" |
| 真机使用 | 4组×20次 = 80次 | **2组×10次 = 20次**（仅展示性运行） |

#### "媲美"叙事的话术模板

> ❌ 原话术（压力高）："ParetoZoom使Hypervolume提高10%以上，量子方法在同等求解预算下不劣于经典多目标进化算法。"
>
> ✅ 修订话术（压力低）："在38变量规模的AlCoCrFeNi-C成分优化问题上，基于CIM光量子真机的AP³框架达到了与NSGA-II经典方法**同等数量级**的Pareto前沿质量（HV差异<15%）。考虑到CIM的**毫秒级求解速度**和**室温运行**的运维优势，以及方案展示的**向7-8元体系扩展的潜力**，量子方法为HEA成分优化提供了一条**可行且可扩展**的技术路径。"

### 4.3 "媲美"叙事的优势

| 优势 | 说明 |
|------|------|
| **降低统计压力** | 不需要p < 0.01的显著性证明，只需展示"在同一数量级"的 descriptive statistics |
| **规避"量子优势"争议** | 文献（arXiv:2203.17181, arXiv:1901.08927）已指出CIM在中小规模上未必超越经典，"媲美"叙事与文献一致 |
| **聚焦编码创新** | 将评委注意力从"量子是否更好"转移到"PrecisionSplit编码是否有效"——这是方案的真正创新点 |

## 六、修订后的论题-结论-理由（针对用户约束）

### 论题R1：在真机额度有限约束下，项目仍能在CIM上产生可信的展示性结果

**结论：✅ 可行，但需严格的"模拟器为主、真机为辅"策略**

**理由：**
1. **模拟器与真机API一致**：kaiwu SDK的模拟器与真机共享同一API，模拟器上开发的代码零成本切换至真机。这意味着全部算法验证（消融、Baseline对比、敏感性分析）可在模拟器上完成，真机仅用于"最终验证"。
2. **真机使用聚焦展示价值**：将有限的~50次真机提交集中在（a）一致性检验（10次）、（b）P2截断验证（10次）、（c）PenaltyFlex验证（15次）、（d）ParetoZoom展示（20次）。这四个场景覆盖了"可信性"和"展示性"的双重需求。
3. **统计严谨性不依赖真机重复**：实验0/1/2/4的统计要求（≥20次重复）全部在模拟器上满足。真机上的10次重复仅用于"一致性检验"和"展示性运行"，不要求严格的显著性检验——这规避了i.i.d.假设的风险。
4. **⚠️ 真机数据与模拟器数据的整合风险**：答辩中若同时展示模拟器数据（消融实验）和真机数据（Pareto前沿），需明确标注数据来源。评委可能质疑"为什么消融实验不用真机"——需准备回应："消融实验验证的是算法逻辑，与硬件无关；真机数据用于验证算法在物理硬件上的可部署性。"

**隐性假设：**
- **假设R1a**：模拟器与真机的"行为等价性"足以支持算法验证——即模拟器上最优的编码方案、惩罚策略、前沿探索策略在真机上不会系统性失效。
- **假设R1b**：评委接受"模拟器完成核心实验+真机完成验证展示"的分工逻辑。
- **假设R1c**：~50次真机提交足以产生"视觉上可信"的Pareto前沿（即散点图上有足够多的非支配点）。

**逻辑漏洞检查：**
- **漏洞R1a**：若真机-模拟器一致性检验显示显著差异（如真机解质量系统性低于模拟器20%以上），则全部模拟器数据的"外部效度"存疑。需在阶段1.1设计"快速失败"机制：若10次一致性检验中真机最优解与模拟器最优解的偏差>15%，则暂停真机实验，分析原因（可能是参数迁移失败或精度问题）。
- **漏洞R1b**：ParetoZoom真机展示仅用2组权重×10次，可能产生稀疏的前沿点。需在模拟器上预先确定"最可能产生丰富Pareto点"的权重组合，避免真机运行后前沿点过少。

### 论题R2：P2约束的精度问题可通过截断/线性化/放大策略在真机上有效实现

**结论：✅ 可行，但需在模拟器上预先验证截断策略的影响**

**理由：**
1. **P2是唯一的问题区域**：除P2交叉项（0.000972~0.24879）外，全部其他系数（P0、f₁、f₂、f₃、P2线性项）均在CIM的可分辨范围内。这意味着仅需对P2进行"真机友好化"，其余QUBO矩阵可直接迁移。
2. **截断策略的预期影响小**：P2的21个交叉项中，仅6个系数<0.01（x₃₅×x₁₄~x₁₇、x₃₆×x₁₄~x₁₅、x₃₇×x₁₄）。截断这6个小项后，P2的最大约束强度损失<5%（因最大项0.24879保留）。
3. **模拟器预验证降低风险**：在模拟器上对比"完整P2" vs "截断P2(threshold=0.01)"的Pareto前沿，若HV差异<5%，则截断策略安全。此预验证不消耗真机额度。
4. **备选方案充足**：若截断影响>15%，可改用线性化P2（方案B）或放大P2（方案C）。两种方案均不增加真机复杂度，仅需调整模拟器上的系数注入逻辑。

**隐性假设：**
- **假设R2a**：CIM的噪声floor在0.01量级（即系数<0.01时信号被噪声淹没）。此假设需通过阶段1.2的P2截断验证实验确认。
- **假设R2b**：P2截断后，P1（碳化物抑制）的约束强度足以单独覆盖碳化物风险——即P1+P2截断版 ≈ P1+P2完整版在碳化物抑制上的等效性。
- **假设R2c**：评委接受"真机版本对P2进行了精度适配"的技术说明，不将其视为"方案缺陷"。

**逻辑漏洞检查：**
- **漏洞R2a**：若CIM的实际噪声floor高于预期（如0.05而非0.01），则截断阈值需上调，可能导致更多P2交叉项被截断，影响增大。解决方案：阶段1.2的P2截断验证实验应测试多个阈值（0.005, 0.01, 0.02），而非单一阈值。
- **漏洞R2b**：P2的物理叙事（"抑制C-Cr协同效应"）在截断/线性化后弱化。若答辩中评委追问"P2如何体现协同效应"，需准备回应："在模拟器版本中P2完整实现了协同抑制；真机版本因硬件精度限制进行了适配，但P1的绝对含量抑制仍有效，且模拟器验证表明截断对整体Pareto前沿影响<5%。"

### 论题R3："媲美"叙事比"超越"叙事更适合当前项目约束

**结论：✅ 强烈推荐，与文献一致且降低全部实验压力**

**理由：**
1. **与文献一致**：arXiv:2203.17181和arXiv:1901.08927均指出CIM在中小规模问题上未必超越经典方法，甚至可能不如经典模拟。"媲美"叙事与学术共识一致，避免了"夸大量子优势"的诚信风险。
2. **降低实验3的统计压力**：原目标"HV_ratio > 1.10, p < 0.01"需要大量重复和严格检验。修订目标"HV_ratio ∈ [0.85, 1.15]"只需描述性统计（均值±SD），10次重复即可满足展示需求。
3. **聚焦真正的创新点**：方案的核心创新是PrecisionSplit编码和PenaltyFlex自适应惩罚——这些是**经典-量子混合算法**的创新，不依赖于"量子超越经典"。将叙事焦点从"量子优越性"转移到"编码效率+约束处理"，更符合方案的实际贡献。
4. **真机额度友好**："媲美"叙事仅需2组权重×10次=20次真机提交即可生成展示数据，而"超越"叙事可能需要≥20次重复×多组权重才能通过统计检验。

**隐性假设：**
- **假设R3a**：NSGA-II在38变量上的HV值不会高到使"媲美"目标（HV_ratio ≥ 0.90）难以达到。若NSGA-II的HV显著高于CIM（如HV_ratio < 0.70），则"媲美"叙事也面临挑战。
- **假设R3b**：评委接受"量子可行性+可扩展性"作为替代"量子优势"的叙事框架。
- **假设R3c**：CIM的"毫秒级求解速度"和"室温运行"作为"运维优势"的论据，在挑战杯评审中被视为有效加分项。

**逻辑漏洞检查：**
- **漏洞R3a**：若实验3显示HV_ratio < 0.80（量子显著劣于经典），则"媲美"叙事失效。需在模拟器上预先运行NSGA-II对比，若发现此风险，则调整叙事为"当前规模经典方法更优，但量子方法展示了向更大规模扩展的潜力"。
- **漏洞R3b**："毫秒级求解速度"的对比需公平——若NSGA-II在38变量上也仅需毫秒级，则此优势不成立。需在实验3中同时报告wall-clock时间，确保"速度优势"有数据支撑。

## 八、最终建议：有限额度下的最优执行策略

### 8.1 核心执行原则

```
1. 模拟器 = 算法验证平台（消融、Baseline、敏感性、P2截断预验证）
2. 真机 = 展示验证平台（一致性检验、最终Pareto前沿、精度边界探测）
3. 叙事 = "编码创新+约束处理创新"为主，"量子可行性+可扩展性"为辅
4. 经典对比 = "媲美"而非"超越"，降低统计压力，聚焦同等数量级
```

### 8.2 真机额度分配（≤50次）

| 优先级 | 场景 | 次数 | 不可替代性理由 |
|--------|------|------|---------------|
| **P0** | 真机-模拟器一致性检验 | 10次 | 验证模拟器数据的外部效度 |
| **P0** | P2截断验证 | 10次 | 确认精度适配策略有效 |
| **P1** | ParetoZoom真机展示 | 20次 | 答辩核心图表（图8）的数据来源 |
| **P1** | PenaltyFlex真机验证 | 15次 | 证明自适应惩罚在物理硬件上有效 |
| **P2** | 额外权重探索 | 5次 | 若前沿点过少时的补充运行 |

### 8.3 答辩叙事框架（修订版）

> **"AlCoCrFeNi-C高熵合金成分优化的核心挑战是：在严格物理约束下高效搜索巨大成分空间。传统方法在约束处理和Pareto前沿探索上存在瓶颈。我们提出AP³框架，通过三项技术创新——PrecisionSplit分层编码（20.8%压缩率）、PenaltyFlex自适应惩罚、ParetoZoom动态前沿探索——首次在光量子真机上实现了HEA成分优化的完整pipeline。实验表明，AP³在模拟器上显著优于朴素Baseline（消融实验验证），且在CIM光量子真机上达到了与经典NSGA-II方法同等数量级的Pareto前沿质量，同时展示了向7-8元体系扩展的潜力。"

### 8.4 风险对冲

| 风险 | 触发条件 | 对冲方案 |
|------|---------|---------|
| 真机-模拟器差异过大 | 一致性检验偏差>15% | 暂停真机实验，分析原因；若无法解决，则全部使用模拟器数据，真机仅作为"概念验证"提及 |
| P2截断影响过大 | HV损失>15% | 改用线性化P2或放大P2，调整叙事为"P1+P2合并约束" |
| NSGA-II显著优于CIM | HV_ratio < 0.80 | 调整叙事为"当前规模经典更优，但量子展示了扩展潜力"，强调编码创新而非量子性能 |
| 真机额度不足50次 | 实际可用<30次 | 优先保P0（一致性10次 + P2截断10次），ParetoZoom展示压缩至2组×5次=10次 |
