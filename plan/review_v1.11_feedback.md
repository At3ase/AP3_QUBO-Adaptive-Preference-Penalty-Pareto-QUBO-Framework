## 一、致命缺陷（CRITICAL — 决定方案可行性）

### [C1] PenaltyFlex 软约束初始化死锁：λ=0 导致自适应永远失效

**位置**：§3.2.5 算法伪代码，第 290 行

**问题描述**：

算法初始化 `λ_soft⁽⁰⁾ = (0.0, 0.0)`，更新公式为：

```
λ_j^(t+1) = λ_j^(t) × exp( α · tanh(v̄_j − ε_j) )
```

当 λ_j⁽⁰⁾ = 0 时，无论指数项取何值：
- `λ_j⁽¹⁾ = 0 × exp(...) = 0`
- `λ_j⁽²⁾ = 0 × exp(...) = 0`
- ……

**λ 将永远停留在 0，P1（碳化物抑制）和 P2（C-Cr 耦合）软约束永远不会生效。**

数值验证（Python）：
```
λ=0.0,  v̄=0.05, ε=0.02, α=0.8:
λ_next = 0.0 × exp(0.8 × tanh(0.05-0.02)) = 0.0  ← 死锁
λ=0.05, same params:
λ_next = 0.05 × exp(0.024) = 0.0512              ← 正常演化
```

这导致整个 PenaltyFlex 机制（§3.2.1-3.2.5，约 120 行）在逻辑上完全失效。量子优化器将忽略 P1 和 P2 约束，仅依赖 P0 硬约束（成分和 = 100%），得到的解可能严重违反碳化物抑制要求。

**修复建议**：
```diff
- 初始λ_soft⁽⁰⁾ = (0.0, 0.0)  // (carbide, CCr)
+ 初始λ_soft⁽⁰⁾ = (0.05, 0.05)  // 小正值，保证乘性更新可演化
```

同时考虑增加**加性启动机制**——前 2 轮使用加性更新建立非零基线：
```
IF t ≤ 2:
    λ_j^(t+1) = λ_j^(t) + α_add · v̄_j   // 加性阶段
ELSE:
    λ_j^(t+1) = λ_j^(t) × exp(α · tanh(v̄_j − ε_j))   // 乘性阶段
```

**严重性**：致命。不修复则整个 PenaltyFlex 架构不可运行。

### [C2] P2 约束（C-Cr 耦合）的 H_max 计算存在系统性量级错误，所有展开系数偏差 10 倍

**位置**：§3.2.3，第 195-221 行

**问题描述**：

文档给出的 H_max：
```
H_max = c_C^{max} × c_Cr^{max} = 1.75% × 36.75% = 0.000643125
```

数值验证：
| 单位体系 | c_C^{max} × c_Cr^{max} | 等于文档值？ |
|----------|------------------------|-------------|
| 百分比² (1.75 × 36.75) | **64.3125** | ❌ 差 100,000 倍 |
| 小数² (0.0175 × 0.3675) | **0.00643125** | ❌ 差 10 倍 |
| 文档值 | **0.000643125** | — |

**文档的 `0.000643125` 不对应任何自洽的单位体系。**

进一步追溯：若从文档随后给出的展开系数（0.194, 0.00972）反推，则实际使用的 H_max ≈ 6.43，即：
```
H_max_implied = 1.75 × 36.75 / 10 = 6.43125
```
但与文档公式 `c_C^{max} × c_Cr^{max}` 矛盾。

**正确推导**（以百分比为单位，即文档全文一致采用的惯例）：

```
c_C   = 0.25 × Σ_{k=0}^{2} 2^k · x_{35+k}         ∈ [0, 1.75]   (%)
c_Cr  = 5.0 + 0.25 × Σ_{j=0}^{6} 2^j · x_{14+j}    ∈ [5.0, 36.75] (%)

H_CCr = c_C × c_Cr / H_max^correct
H_max^correct = 1.75 × 36.75 = 64.3125   // 归一化到 [0, 1]

线性项 (k=0): 1.25 / 64.3125 = 0.01944   ← 文档写 0.194（差 10 倍）
交叉项 (k=0,j=0): 0.0625 / 64.3125 = 0.000972  ← 文档写 0.00972（差 10 倍）
```

**影响范围**：

| 受影响内容 | 文档值（错误） | 正确值 | 偏差 |
|-----------|-------------|--------|------|
| H_max | 0.000643125 | 64.3125 (%²) 或 0.00643125 (小数²) | 公式需修正 |
| 线性系数 (x₃₅) | 0.194 | 0.0194 | ×10 |
| 交叉项基数 | 0.00972 | 0.000972 | ×10 |
| 最大交叉项 (x₃₇×x₂₀) | 2.488 | 0.2488 | ×10 |
| P2 最大贡献 (ω=0.1, λ=1.0) | ~0.25 | ~0.025 | ×10 |

量级评估随之改变：P2 约束实际贡献约为 f₁^norm 的 1/40 至 1/4（文档声称的"同量级"不成立）。

**修复建议**：

方案 A（推荐）：统一使用百分比² 单位归一化
```
H_max = c_C^{max} × c_Cr^{max} = 1.75 × 36.75 = 64.3125
H_CCr = c_C × c_Cr / 64.3125
// 线性系数 (k=0): 0.0194
// 交叉项基数: 0.000972
```

方案 B：保持文档的展开系数值（0.194, 0.00972），但明确标注 `H_max = c_C^{max} × c_Cr^{max} / 10 = 6.43125`，并解释为何引入额外的 ×10 缩放。若采用此方案，P2 约束强度是方案 A 的 10 倍，需在量级验证部分确认不会压倒 f₂/f₃ 目标。

**严重性**：致命。系数偏差 10 倍意味着 P2 约束的实际强度与设计意图严重不符——若代码按正确 H_max 实现（方案 A），P2 将几乎不起作用；若按文档系数实现，则需修正 H_max 的公式说明。

## 二、严重问题（HIGH — 影响方案的正确性或可信度）

### [H1] P1 碳化物惩罚项的物理论证存在概念性错误

**位置**：§3.2.2，第 176-181 行

**原文**：
> 改用纯二次型 `(c_C − 0.8%)²` 可精确嵌入QUBO，且对 c_C < 0.8% 产生**负贡献（即奖励低C成分）**，这在物理上是**有利的**——低C固溶区本身即为期望方向。

**问题分析**：

`(c_C − 0.8%)²` 在 c_C < 0.8% 时不会产生"负贡献"。该二次型最小值为 0（在 c_C = 0.8% 处），对所有 c_C ≠ 0.8% 的值均给出 **正惩罚**：

| c_C | (c_C − 0.8)² | 性质 |
|-----|-------------|------|
| 0% | 0.64 | **正惩罚**（非负贡献） |
| 0.25% | 0.3025 | 正惩罚 |
| 0.5% | 0.09 | 正惩罚 |
| 0.8% | 0 | 最小值（零惩罚） |
| 1.0% | 0.04 | 正惩罚 |
| 1.75% | 0.9025 | 正惩罚 |

**物理含义被曲解**：`(c_C − 0.8%)²` 是一个以 0.8% 为中心的**软目标**（soft target），同时惩罚过低 C 和过高 C。它并不"奖励低 C"——c_C = 0 的惩罚（0.64）大于 c_C = 0.8% 的惩罚（0），c_C = 0 实际上比 c_C = 0.8% 更不受欢迎。

与原始分段函数 `max(0, c_C − 0.8%)²` 的比较：

| c_C | max(0, c_C−0.8)² | (c_C−0.8)² | 新方案 vs 旧方案 |
|-----|-------------------|------------|----------------|
| 0% | 0 | 0.64 | 新方案**更差**（多了 0.64 的惩罚） |
| 0.5% | 0 | 0.09 | 新方案更差 |
| 0.8% | 0 | 0 | 相同 |
| 1.75% | 0.9025 | 0.9025 | 相同 |

**修正后的物理解释**：

二次型 `(c_C − 0.8%)²` 是原始分段函数在 QUBO 约束下的**近似**，本质是将"单侧上界"转换为"双侧软目标"。其对 c_C < 0.8% 的额外惩罚是**QUBO 可实现性的代价**，而非物理上的设计意图。在实践中，由于该额外惩罚的绝对量级（~0.1-0.6）远小于 P0 硬约束的典型惩罚（λ_sum=10~20 时 >10），且低 C 本身对ΔH_mix 有利（C 与过渡金属的强负混合焓），优化器通常仍能在 Pareto 前沿上找到 c_C < 0.8% 的有效解。

**修复建议**：重写 §3.2.2 中关于"负贡献"的段落，准确描述二次近似的 trade-off。

**严重性**：高。不影响代码正确性，但错误的物理论证会误导后续开发者和审稿人。

### [H3] 目标函数归一化存在隐性不对称，"等权重 = 等偏好"直觉不成立

**位置**：§4.1 归一化层

三个归一化目标的实际动态范围差异显著（对等权重 0.33）：

| 目标 | 归一化范围 | 等权重贡献范围 | 动态跨度 | 相对影响力 |
|------|-----------|--------------|---------|-----------|
| f₁^norm | [−0.67, +0.17] | [−0.22, +0.056] | **0.276** | 基准 |
| f₂^norm | [0.60, 0.90] | [0.20, 0.30] | **0.099** | **0.36× f₁** |
| f₃^norm | [0, 1] | [0, 0.33] | **0.33** | 1.2× f₁ |

在等权重 (0.33, 0.33, 0.33) 下，f₁ 的实际优化影响力（跨可达成目标范围）约为 f₂ 的 **2.8 倍**。用户直觉上认为"33%-33%-33% 意味着三者同等重要"，但实际执行中 f₂ 被边缘化。

此外，f₁^norm 可以取负值（优化方向正确时），而 f₂^norm 和 f₃^norm 始终为正。这种符号不对称意味着：
- 优化器可以通过改善 f₁（使ΔH_mix 更负）来**降低** H_obj（正确行为）
- 但无法通过极端优化 f₂（降低密度到物理下限）来同等地降低 H_obj——f₂ 的贡献始终为正且下限受限

**物理上这是合理的**（负混合焓确实有利），但需要在文档中**显式标注**，让用户理解权重并非等比例映射。

**修复建议**：
1. 在 §4.1 增加"权重校准说明"子节，给出建议权重与物理偏好的映射表
2. 考虑将 f₂^norm 和 f₃^norm 也做去均值处理（减去最小值，使范围为 [0, range]），减少符号不对称

**严重性**：高（用户接口层面）。代码实现不影响，但用户若不了解此不对称性，将无法正确设定偏好权重。

## 三、中等问题（MEDIUM — 建议修复，不阻塞开发）

### [M1] 非零 C 含量时等原子比主元成分不可达

**位置**：§2.5 统一步长验证

文档以"等原子比各主元 20%、C 0%"为例证明 K=300 可达，但**未讨论 c_C > 0 时的约束**。分析如下：

```
Σc_i + c_C = 100, 其中 c_i = 5.0 + 0.25·k_i, c_C = 0.25·m

5×5.0 + 0.25·Σk_i + 0.25·m = 100
Σk_i = 300 − m   (m ∈ [0, 7])

5 个主元等原子比 → k_i 需全部相等 → Σk_i 需是 5 的倍数
300 − m 是 5 的倍数 ⇔ m 是 5 的倍数
m ∈ {0, 5}  → c_C ∈ {0%, 1.25%}
```

**结论**：仅在 c_C = 0% 或 c_C = 1.25% 时，5 主元可严格等原子比且满足成分和非 100%。其他 C 含量时，主元必须不等比。

这不是方案缺陷（优化器可自然处理），但文档的"等原子比示例"过于简化，建议补充此分析。

### [M2] f₁ 仅最小化 ΔH_mix，忽略 ΔS_mix 贡献

**位置**：§4.1 f₁ 目标函数

真实热力学稳定性判据为 `ΔG_mix = ΔH_mix − T·ΔS_mix`。高温（>1000 °C）时熵项的贡献不可忽略：
- 等原子比 5 主元：T·ΔS_mix ≈ 1300 × 1.61R ≈ 17.4 kJ/mol（与ΔH_mix 同量级）
- f₁ 仅优化焓项可能遗漏"ΔH 不最优但 ΔS 很高"的候选成分

**建议**：在文档中注明此简化假设，并在后处理 §7 中用 Ω 判据（已含熵项）进行兜底验证。若后续扩展，可考虑加入 `Ω = T_m·ΔS_mix/|ΔH_mix|` 作为 f₄ 目标（最大化 Ω）。

---

### [M3] C 的 γ 折扣因子缺乏物理严格性

**位置**：§4.1 f₁ 中 `γ = 0.2~0.3`

间隙 C 的混合焓修正采用常数折扣因子 γ，这是工程近似而非物理推导。在 Miedema 模型中，C-TM 相互作用涉及：
1. 间隙位的应变能（取决于基体晶格类型 BCC/FCC）
2. C 在间隙位的化学势（取决于最近邻 TM 种类）

这些效应在不同主元成分下变化，常数 γ 无法捕捉。

**建议**：
1. 标注 γ 为"唯象折扣因子"（phenomenological discount factor）而非"经验近似"
2. 在敏感性分析中增加 γ=0.1 和 γ=0.5 的对比（文档已提到，需确保执行）
3. 考虑未来用 DFT 计算结果替代常数 γ（如 VASP 计算的 C 在 AlCoCrFeNi 各相的溶解焓）

---

### [M4] 凸性检验仅对 f₁-f₂ 平面投影进行

**位置**：§4.2.2 CONVEXITY_TEST

文档自身承认此限制（"完整 3D 凸包检验推荐用于生产环境"），但存在一个未提及的问题：f₂-f₃ 之间的 trade-off 弱是假设，如果在实际运行中发现 f₁-f₃ 也存在显著 trade-off，2D 检验将遗漏该方向的非凸性。

**建议**：在实现时对三个投影平面（f₁-f₂, f₁-f₃, f₂-f₃）均执行凸性检验，取最坏结果。

---

### [M5] C 密度值 ρ_C = 2.27 g/cm³（石墨）的适用范围

**位置**：§4.1 f₂ 中 ρ_C 取值

C 作为间隙原子时，对合金密度的有效贡献与石墨的密度不同。在 BCC/FCC 金属基体中，间隙 C 引起晶格膨胀，其对 Vegard 定律密度的贡献应基于**原子体积**而非石墨密度。

设间隙 C 在 Fe 基体中的偏摩尔体积约为 5.7 Å³/atom（文献值），则等效密度贡献远小于 2.27 g/cm³。但在 c_C < 1% 时，该近似引入的误差确实 < 0.5%，文档的自评估基本合理。

**建议**：在文档中补充 "C 密度有效值 ≈ 1.8 g/cm³（基于偏摩尔体积估算，参考文献 XXX）" ，供实现时对比选择。

### [L4] 附录 A.1 等原子比 ΔH_mix 计算注释不够仔细

**位置**：§9（原附录 A.1），第 708 行

> 等原子比AlCoCrFeNi预测：ΔH_mix ≈ 4 × (−19−10−11−22−4−1−7−1−2)/10 ≈ **−12.2 kJ/mol**

该速算仅包含 10 对二元相互作用中的 9 对（遗漏了 Co-Cr = −4 吗？）。手动验证：
- Al-Co: −19, Al-Cr: −10, Al-Fe: −11, Al-Ni: −22
- Co-Cr: −4, Co-Fe: −1, Co-Ni: 0
- Cr-Fe: −1, Cr-Ni: −7
- Fe-Ni: −2

共 10 对，求和 = (−19−10−11−22−4−1+0−1−7−2) = −77
ΔH_mix = 4 × (−77) × (1/5)² = 4 × (−77) × 1/25 = 4 × (−3.08) = −12.32 kJ/mol

数值 −12.32 ≈ −12.2 大致吻合（可能四舍五入导致）。但文档写 "除以 10" 应为 "除以 10 对" 或 "乘以 (1/5)² = 1/25" 再乘以 4 得到 4/25。建议在文档中展示完整推导以避免读者困惑。

## 六、总体评价

**方案成熟度**：约 75%
