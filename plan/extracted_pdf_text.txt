三、约束处理与惩罚项设计
3.1 硬约束：成分和 = 100%（含C）
六种元素（Al, Co, Cr, Fe, Ni, C）的原子百分比之和严格等于100%。C虽为间隙元素且含量低，但在
约束方程中占据完整权重。
惩罚项形式：
H_sum = λ_sum × ( Σ_{k ∈ {Al,Co,Cr,Fe,Ni,C}} c_k − 100 )²
展开为QUBO：
定义 S = Σ c_k = Σ(base_k) + Σ(step_k × Σ 2^j x_{k,j})
常数基线：S_const = 5×5.0 + 0.0 = 25.0%（主元最低值之和）
变量部分：S_var = S − S_const
量级归一化：为避免惩罚项系数与（kJ/mol量级）相差过大，对S_var做无量纲化处理：
S_var' = S_var / 75  // 归一化
// 分母 75 的推导： S_var = 总成分  − 基线  = 100% − 5×5.0% = 75% （等原子比目标值）
// S_var = 0.25% × K, K ∈  [0, 642], 故  S_var ∈  [0, 160.5] （百分比单位）
// S_var' = S_var / 75 ∈  [0, 2.14] ，等原子比（ K=300 ）时  S_var'=1 ，惩罚 =0
H_penalty = λ_sum × (S_var' − 1)²
          = λ_sum × [(S_var/75) − 1]²

          = (λ_sum/5625) × [S_var² − 150·S_var + 5625]

3.2 Feedback-Driven Penalty Adaptation (PenaltyFlex)
核心思想：惩罚项系数根据当前解的质量反馈和用户对不同约束的偏好权重动态调整。经典-量子混合
迭代：量子退火器负责单次QUBO采样，经典后处理层分析结果并调整下一轮参数，再通过kaiwu

AP3-QUBO 技术路线 · 第一性原理解释版
目标：让第一次听到这个项目的人，能从"为什么要找合金配方"一路理解到"量子计算机怎么帮
我们找"。 核心原则：先问"为什么"，再问"是什么"。
一、从一个简单的问题开始：为什么合金配方这么难找？
1.1 一切从"材料决定性能"说起
想象你要造一架能在 1200°C 高温下工作的航天发动机叶片。它不能熔化、不能变形、不能突然脆裂
——这些全都取决于你用了什么材料。
合金（Alloy）就是把几种金属元素像调鸡尾酒一样混在一起，希望它们组合出单一金属做不到的性
能。比如铝很轻但太软，钢很硬但太重，如果把铝、钴、铬、铁、镍按某种比例混合，可能得到一种
又轻又硬又耐高温的"超级金属"。
这就是高熵合金（High-Entropy Alloy, HEA）的想法：不再只加一点点"调料"（传统合金），而是让
四五种主元素各占差不多相等的比例，像一杯五种基酒各占 20% 的鸡尾酒。
1.2 调一杯好鸡尾酒，为什么那么难？
现在问题来了：你有 6 种元素（Al、Co、Cr、Fe、Ni，再加上一点点碳 C），每种元素的占比可以从
0% 到 35% 不等，而且加起来必须正好 100%。
假设我们只按 0.25% 的步长来调（比如 20.00%、20.25%、20.50%……），6 种元素的组合可能性是
一个天文数字。如果让一台普通计算机把所有配方一个个试过去，试到太阳熄灭都试不完。
更麻烦的是，你要同时满足三个互相打架的目标： - 热力学稳定性高（合金在高温下不分解、不生成
有害相） - 密度低（航天器每一克重量都是钱） - 成本低（钴比铁贵 50 倍，全用钴造不起）
提高铝含量 → 密度降低（好），但热力学稳定性可能下降（坏）。 提高碳含量 → 热力学更稳定
（好），但可能析出脆性碳化物（坏）。 降低钴含量 → 成本降低（好），但可能牺牲高温性能
（坏）。
没有单一"最好"的配方。就像买车时"便宜、省油、动力强"三者不可兼得，你必须做权衡。材料科学
家需要的不是"一个答案"，而是一整张"权衡地图"，让工程师根据具体任务（是造涡轮叶片还是热障
涂层）自己挑选。
二、传统方法：试错的困境
2.1 穷举法：大海捞针
最笨的办法是穷举（Brute-force）：把所有可能的配方列出来，逐个算性能。但前面说了，搜索空间
大到宇宙尺度，根本不可行。

2.2 网格搜索：盲人摸象
稍微聪明一点的是网格搜索：在配方空间里均匀撒一些采样点，比如每隔 5% 取一个配方。问题是
——最优配方可能正好落在两个采样点之间的"缝隙"里，你永远摸不到。而且你撒的点越多，计算量
越大。
2.3 梯度下降：在黑暗山谷中摸下坡路
经典优化算法（比如梯度下降，Gradient Descent）的思路是：站在当前配方上，看看往哪个方向走
能让目标变好，然后一步步走下去。
这就像一个盲人在黑暗的山谷里摸下坡路：他能感觉到脚下的坡度，顺着最陡的方向往下走。但如果
山谷里有多个坑（局部最优），他可能掉进一个浅坑就以为到了谷底，而真正的最深谷在隔壁山丘后
面——他永远翻不过去，因为他只能"摸脚下的坡度"，不能"看穿整座山"。
合金配方空间充满了这样的"山丘和山谷"，经典算法很容易被困在一个"看起来不错"的配方里，错过真
正更好的配方。
2.4 多目标进化算法：一群蚂蚁慢慢爬
经典多目标算法（比如后面会讲到的 NSGA-II）用一群"解"像生物进化一样互相竞争、交叉、变异，
慢慢逼近最优区域。这像一群蚂蚁在草原上随机爬行，留下信息素，最终找到食物。但它需要成千上
万次评估，在计算资源昂贵时效率不高。
三、量子计算：一种新的"搜索方式"
3.1 量子隧穿：穿过山丘，而非翻过山丘
【量子退火（Quantum Annealing）】：一种利用量子力学特性来寻找最优解的算法。类比：经典
优化像一个人在黑暗山谷中摸黑下坡，遇到山丘只能翻过去；量子退火则像一个能穿墙而过的幽灵，
可以穿过山丘直接到达更深的谷底。
这个"穿墙"的能力在物理学里叫量子隧穿（Quantum Tunneling）。在量子世界里，粒子有一定概率
穿过经典物理学认为"不可能穿过"的势垒。量子退火器利用这个特性，让系统有概率从局部最优"跳"出
来，继续寻找全局最优。
3.2 为什么量子计算适合"配方优化"？
我们的配方优化问题有一个天然优势：每种元素的含量可以离散化为"是 20.00% 还是 20.25%"这样的
