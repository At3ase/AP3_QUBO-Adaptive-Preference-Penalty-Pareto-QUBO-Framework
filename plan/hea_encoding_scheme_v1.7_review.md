### 🟡 新问题 2：ParetoZoom 算法伪代码未反映目标归一化

**问题定位**：§4.2.3 算法第 30 行

算法伪代码：
```
30. H_single ← w₁·f₁ + w₂·f₂ + w₃·f₃ + H_penalty(λ_PenaltyFlex_final)
```

但 §4.1 目标归一化层规定 QUBO 中实际最小化的是：
```

```

两者不一致。`f_i` 是原始目标值（ΔH_mix kJ/mol、密度 g/cm³、成本任意单位），`f_i^norm` 是归一化到 [0,1] 的值。

**建议修正**：

```
30. H_single ← w₁·f₁^norm + w₂·f₂^norm + w₃·f₃^norm + H_penalty(λ_PenaltyFlex_final)
     // f_i^norm 按 §4.1 归一化层：粗网格阶段用物理先验，ParetoZoom 阶段用动态归一化
```

### 🟡 新问题 3：动态归一化切换后的 PenaltyFlex λ 一致性

**问题定位**：§4.1 目标归一化层 + §4.2.5 双层自适应协同流程

**问题分析**：

方案设计了两阶段归一化：
1. **粗网格阶段**（6 组）：使用物理先验归一化 `f₁/30, f₂/10, f₃/c_max`
2. **ParetoZoom 阶段**：使用动态归一化 `(f_i − f_i^min)/(f_i^max − f_i^min)`

粗网格阶段跑完整 PenaltyFlex，产出的 λ* 是在 **物理先验归一化** 的 QUBO 系数下优化的。当切换到动态归一化后，QUBO 矩阵中 f₁, f₂, f₃ 的系数发生整体重新缩放，惩罚项 H_sum、H_carbide 的系数保持不变。

这意味着：
- **惩罚项与目标项的相对权重发生变化**
- 粗网格产出的 λ* 作为 ParetoZoom 的 warm-start，可能不再是最优的

**定量估计**：

物理先验归一化下：f₁^norm ∈ [−0.67, 0.17]（范围 ~0.83），f₂^norm ∈ [0.6, 0.9]（范围 ~0.3）
动态归一化下：f₁^norm ∈ [0, 1]，f₂^norm ∈ [0, 1]

目标函数的有效数值范围从 ~0.3-0.83 扩大到 [0,1]。如果 λ_sum 保持不变，惩罚项相对于目标项的 **有效权重减小**。

**建议修正**：

```
方案 A（推荐）：归一化切换后重新初始化 PenaltyFlex
  粗网格完成后 → 计算动态归一化参数 → 重置 λ 为初始值 (0.1, 0, 0)
  → 对 ParetoZoom 的第一组权重重新跑完整 PenaltyFlex
  → 后续权重使用新的 warm-start 缓存
  代价：额外 10-15 轮量子提交（毫秒级，可忽略）

方案 B：对 λ 做归一化感知的重缩放
  λ_new = λ_old × (range_old / range_new)
  其中 range 是目标函数在前一化前后的数值范围比
  近似但不精确——惩罚项-目标项平衡是非线性的

方案 C：统一使用物理先验归一化
  放弃动态归一化，全程使用 f₁/30, f₂/10, f₃/c_max
  简化流程，代价是权重不完全对应 [0,1] 语义
  对 6 元素小规模问题，物理先验归一化已足够精确
```

> 📐 **分析**：由于 38 变量 QUBO 单次求解为毫秒级，方案 A 的额外开销可忽略。建议采用方案 A，或在文档中明确标注归一化切换时 λ 的处理策略。

### 🟡 新问题 4：凸性检验仅检查 f₁-f₂ 平面投影

**问题定位**：§4.2.2 CONVEXITY_TEST

**分析**：

凸性检验的叉积公式：
```
cross = (y_i.f₂ − y_{i-1}.f₂) × (y_{i+1}.f₁ − y_{i-1}.f₁) − 
         (y_i.f₁ − y_{i-1}.f₁) × (y_{i+1}.f₂ − y_{i-1}.f₂)
```

这仅检查了 **f₁-f₂ 平面投影** 的凸性。三目标 Pareto 前沿可能在 f₁-f₃ 或 f₂-f₃ 投影中存在非凸区域，而在 f₁-f₂ 投影中表现为凸。

**物理动机分析**：
- f₁（形成能）与 f₂（密度）之间的 trade-off 由 Al 含量主导，接近线性 → f₁-f₂ 投影大概率凸
- f₁ 与 f₃（成本）之间由 Co/Ni 含量主导 → 可能接近凸
- f₂ 与 f₃ 之间 trade-off 最弱 → 也最可能出现非凸行为

**实际风险评估**：由于 f₂-f₃ trade-off 较弱（Al 降低密度但成本影响小，Co/Ni 增加成本但对密度也有贡献），在该投影中出现强非凸的可能性较低。f₁-f₂ 单投影检验作为一阶近似是合理的。

**建议修正**：

```
方案 A：扩展至三投影检验
  FOR projection ∈ {(f₁,f₂), (f₁,f₃), (f₂,f₃)}:
      执行 2D CONVEXITY_TEST
  IF 任一投影 nonconvex_ratio > 10%: 触发警告

方案 B：使用 3D 凸包检验
  计算 P₀ 的 3D convex hull
  IF |hull vertices| < |P₀|: 存在内部点 → 非凸

方案 C（推荐）：标注当前为简化检验
  在代码注释中标注 "2D convexity check in f₁-f₂ plane; 
  full 3D check recommended for production"
  f₁-f₂ 是最强 trade-off 的投影面，最具代表性
```

### 🟢 新问题 6：ΔS_mix 公式未说明对 C 的处理

**问题定位**：§7 Ω 判据 `ΔS_mix = −R · Σ c_i · ln(c_i)`

理想混合熵公式中，求和是否包含 C？C 作为间隙元素，其混合熵机制与置换式元素不同。如果 C 占据间隙位而非置换位，其位形熵的计算方式不同（间隙位的亚晶格模型）。

**物理澄清**：
- 如果 C 占据八面体间隙位，应使用双亚晶格模型：`ΔS = −R[Σ c_i^sub·ln(c_i^sub) + β·Σ c_j^int·ln(c_j^int)]`
- 对于 AlCoCrFeNi-C 且 c_C ≪ 1%，C 对 ΔS_mix 的贡献很小（~0.05R），可近似忽略
- 但 ln(c_C) 在 c_C → 0 时发散——数值上需要处理

**建议**：

```
方案 A：ΔS_mix 仅计算 5 种主元
  ΔS_mix = −R · Σ_{i∈{Al,Co,Cr,Fe,Ni}} c_i' · ln(c_i')
  c_i' = c_i / (1 − c_C)  // 主元归一化
  C 的贡献忽略（间隙位混合熵机制不同，且量级小）

方案 B：包含 C 但加说明
  Σ 包含全部 6 种元素（与成分和约束一致）
  标注 "C 的混合熵按置换式近似，实际由间隙亚晶格贡献"
```

## 二、深入验证：关键设计的数学一致性

### 2.1 惩罚项归一化的自洽性验证

v1.7 §3.1 的归一化：

```
S_var' = S_var / 75
H_penalty = λ_sum × (S_var' − 1)²
          = (λ_sum/5625) × [S_var² − 150·S_var + 5625]
```

**验证点 1：coef_i 的正确性**

S_var = 0.25 × (Σ_{主元} Σ 2^j x_{k,j} + Σ 2^j x_{C,j}) = 0.25 × Σ coef_i × x_i

coef_i 取值表：

| x 范围 | 对应元素-位 | coef |
|--------|-----------|------|
| x_0 ~ x_6 | Al: bit 0~6 | 1, 2, 4, 8, 16, 32, 64 |
| x_7 ~ x_13 | Co: bit 0~6 | 同上 |
| x_14 ~ x_20 | Cr: bit 0~6 | 同上 |
| x_21 ~ x_27 | Fe: bit 0~6 | 同上 |
| x_28 ~ x_34 | Ni: bit 0~6 | 同上 |
| x_35 ~ x_37 | C: bit 0~2 | 1, 2, 4 |

展开 S_var²：
- 自平方项 x_i²：coef_i² × x_i（因 x_i² = x_i），QUBO 线性系数 = λ_sum/5625 × coef_i² × 0.25²

  等等——我需更仔细地追踪系数。S_var 以百分比为单位，coef_i 是编码整数的乘子。

  S_var = 0.25 × Σ coef_i × x_i（百分比单位）

  S_var² = (0.25)² × (Σ coef_i x_i)² = 0.0625 × [Σ coef_i² x_i + 2 Σ_{i<j} coef_i coef_j x_i x_j]

  然后 H_penalty = (λ_sum/5625) × [S_var² − 150·S_var + 5625]

  自平方项对 QUBO hi（线性偏置）的贡献 = λ_sum/5625 × 0.0625 × coef_i² × x_i

  交叉项对 QUBO J_{ij} 的贡献 = λ_sum/5625 × 0.0625 × 2 × coef_i × coef_j × x_i x_j

  线性偏置（来自 S_var 的 −150 项）= λ_sum/5625 × 0.25 × (−150) × coef_i × x_i

  常数项 = λ_sum/5625 × 5625 = λ_sum（不依赖 x，不影响优化）

**验证点 2：最大 coef 时的系数范围**

coef_i 最大 = 64（主元最高位）。coef_i² = 4096。
自平方贡献 = λ_sum/5625 × 0.0625 × 4096 = λ_sum × 0.0455

对于 λ_sum ≈ 1（收敛后），最大自平方项系数 ≈ 0.046，与归一化后的目标函数 O(1) 相比偏小约 20×——这暗示惩罚项可能需要 λ_sum 远大于 1 才能有效约束。

实际上这意味着归一化因子 75 可能偏大，导致惩罚项系数被过度缩小。让我检查：

在满足约束时 (S_var=75, S_var'=1)，惩罚=0。
在最坏违反时 (S_var=0 或 S_var=160.5)，惩罚 = (0−1)² = 1 或 (2.14−1)² = 1.30。

所以 λ_sum × 1 是最大惩罚贡献。而目标函数归一化后在 [0,1] 区间，量级为 w_i × O(1)。

如果 w₁ = w₂ = w₃ = 1/3，目标贡献 ≈ 0.33。
约束违反贡献 = λ_sum × 1。

要达到 "约束违反惩罚 ≈ 目标值" 的平衡（标准拉格朗日对偶性），需 λ_sum ≈ 0.33。

但 PenaltyFlex 从 λ_sum = 0.1 开始自适应。
- 如果 v̄_sum = 1%（几乎满足约束），`exp(0.8 × tanh(1 − 1)) = exp(0) = 1` → λ 保持不变
- 如果 v̄_sum = 3%（轻微违反），`exp(0.8 × tanh(2)) ≈ exp(0.77) ≈ 2.16` → λ 上升
- 如果 v̄_sum = 10%（严重违反），`exp(0.8 × tanh(9)) ≈ exp(0.8) ≈ 2.23` → λ 快速上升

从 0.1 开始：0.1 → 0.22 → 0.49 → 1.09 → ... 在 4-5 轮后达到 λ_sum ~1。

这看起来合理。当 λ_sum ≈ 1 时，最大约束违反惩罚 ≈ 1.30，与目标 O(1) 可比。平衡点是合理的。

**结论**：数学自洽，归一化设计正确。✅

### 2.2 H_carbide 的 QUBO 表示精确性验证

v1.7 改为 `H_carbide = (c_C − 0.8)²`。

c_C = 0.25 × (x_35 + 2x_36 + 4x_37) = 0.25 × u，u ∈ {0,1,...,7}

H_carbide = (0.25u − 0.8)² = 0.0625u² − 0.4u + 0.64

在二元变量中：u = x_35 + 2x_36 + 4x_37
u² = x_35² + 4x_36² + 16x_37² + 4x_35x_36 + 8x_35x_37 + 16x_36x_37

由于 x_i² = x_i：
u² = x_35 + 4x_36 + 16x_37 + 4x_35x_36 + 8x_35x_37 + 16x_36x_37

H_carbide = 0.0625(x_35 + 4x_36 + 16x_37 + 4x_35x_36 + 8x_35x_37 + 16x_36x_37) − 0.4(x_35 + 2x_36 + 4x_37) + 0.64

整理：
- x_35 线性系数：0.0625 − 0.4 = −0.3375
- x_36 线性系数：0.25 − 0.8 = −0.55
- x_37 线性系数：1.0 − 1.6 = −0.6
- x_35x_36 二次系数：0.25
- x_35x_37 二次系数：0.5
- x_36x_37 二次系数：1.0
- 常数：0.64

**数值验证**（8 点）：

| u | c_C | (c_C−0.8)² | QUBO 计算值 | 匹配？ |
|---|------|-----------|-----------|-------|
| 0 | 0.00 | 0.64 | 0.64 | ✅ |
| 1 | 0.25 | 0.3025 | 0.64−0.3375=0.3025 | ✅ |
| 2 | 0.50 | 0.09 | 0.64−0.55=0.09 | ✅ |
| 3 | 0.75 | 0.0025 | 0.64−0.3375−0.55+0.25=0.0025 | ✅ |
| 4 | 1.00 | 0.04 | 0.64−0.6=0.04 | ✅ |
| 5 | 1.25 | 0.2025 | 0.64−0.3375−0.6+0.5=0.2025 | ✅ |
| 6 | 1.50 | 0.49 | 0.64−0.55−0.6+1.0=0.49 | ✅ |
| 7 | 1.75 | 0.9025 | 0.64−0.3375−0.55−0.6+0.25+0.5+1.0=0.9025 | ✅ |

**结论**：精确匹配，无近似误差。✅

> 📐 这也验证了 v1.6 审查中的 QUBO 自由度分析是正确的：通过移除 max(0,·) 的不可微拐点，函数变为纯二次型，3 变量 QUBO 的 7 自由度恰好匹配（实际上 3 变量二次型空间正是 7 维，与 8 个离散点有 1 个隐式约束——二次型在 3 个二元变量上的取值满足特定的线性关系，v1.6 的 max(0,·)² 函数违反了这个关系）。

### 2.3 ΔH_mix 折扣因子的自洽性

v1.7 f₁ 拆分为：
```
ΔH_mix = ΔH_mix^substitutional + γ × ΔH_C^interstitial
γ = 0.2~0.3
```

**物理自洽性检查**：

对于 AlCoCrFeNi 等原子比成分，ΔH_mix^substitutional ≈ −12.16 kJ/mol（基于标准 Miedema 值计算：4×[0.2×0.2×(−19−10−11−22)+0.2×0.2×(−4−1+0)+0.2×0.2×(−1−7)+0.2×0.2×(−2)] = ... 让我简化计算）。

如果 c_C = 0.5%，C-TM 混合焓贡献（γ=0.3）：
- 交叉项量级 ≈ 4 × 0.3 × (−30 to −60) × 0.005 × 0.2 ≈ −0.04 to −0.07 kJ/mol

相比 ΔH_mix^substitutional ≈ −12 kJ/mol，间隙贡献约为 0.3-0.6%——可以忽略。C 对 ΔH_mix 的影响主要由 P1 碳化物约束控制，而非 f₁ 目标驱动。

**在 c_C = 1.75%（编码上限）时**：
- 交叉项 ≈ 4 × 0.3 × (−40) × 0.0175 × 0.2 ≈ −0.17 kJ/mol
- 仍然远小于置换贡献

但如果 **不用折扣**（γ=1.0）且 c_C = 1.75%：
- 交叉项 ≈ 4 × (−40) × 0.0175 × 0.2 ≈ −0.56 kJ/mol
- 对于 ΔH_mix 范围 [−20, +5]，−0.56 是显著的（约 2.2%）

**结论**：折扣因子 γ=0.2~0.3 有效地将 C 在 ΔH_mix 中的影响控制在 ~0.5% 以内——远小于其他模型误差来源。f₁ 主要由置换式主元的混合焓主导，物理上合理。✅

### 3.2 C 密度模型的合理性（遗留问题重评估）

v1.7 中 C 的密度仍使用 ρ_C = 2.27（石墨），参与 Vegard 线性混合。之前的审查标记为 "物理偏差"。

**重新评估**：考虑到以下因素，该问题的影响已被多重缓解机制有效控制：

1. **C 含量极低**：c_C ∈ [0, 1.75%]，且 P1 约束实际限制至 ~0.8%
2. **ρ_C 误差的绝对值**：0.8% × (真实值 − 2.27) ≈ 0.8% × ~3 ≈ 0.024 g/cm³
3. **目标归一化**：f₂ 归一化到 [0,1] 后，0.024 g/cm³ 的误差对应的归一化偏差 ≈ 0.024/3 ≈ 0.8%
4. **Vegard 定律本身的误差**：文档标注为 0.5-1%，与 ρ_C 误差量级相当

**结论**：在 c_C ≤ 0.8% 的操作范围内，C 密度模型的误差 **不超过 Vegard 定律本身的固有误差**。方案可接受。若追求极致精度，可在文档中增加一行标注：

```
> **C 密度近似**：C 作为间隙元素的密度贡献使用石墨值近似，在 c_C < 1% 范围内引入的误差 < 0.03 g/cm³（<0.5%），与 Vegard 定律自身精度相当。
```
