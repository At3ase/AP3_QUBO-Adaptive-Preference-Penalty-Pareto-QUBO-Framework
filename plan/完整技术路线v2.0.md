## 一、问题定义：第一性原理起点

### 1.1 核心问题

**我们要解决什么？**

在 AlCoCrFeNi-C 六元高熵合金体系中，找到最优的成分配比（每种元素各占多少原子百分比），使得合金同时满足：
- **热力学稳定性高**（不容易分解或形成有害相）
- **密度低**（航天应用减重需求）
- **成本低**（工程可接受）

**约束条件**：
- 六种元素的原子百分比之和必须严格等于 100%（质量守恒）
- 碳含量不能过高（否则析出碳化物，破坏固溶体结构）
- 碳与铬的协同效应需被抑制（Cr-C 是最强负混合焓对，易形成碳化物）

### 1.2 为什么这个问题难？

**组合爆炸**：即使每种元素只取离散值，六元体系的搜索空间也是天文数字。传统方法（穷举、网格搜索）在有限时间内只能覆盖极小区域。

**多目标冲突**：
- 提高 Al 含量 → 密度降低（好），但热力学稳定性可能下降（坏）
- 提高 C 含量 → 混合焓更负（热力学更稳定，好），但碳化物析出风险上升（坏）
- 降低 Co 含量 → 成本降低（好），但可能牺牲高温性能（坏）

**没有单一"最优解"**：三个目标互相冲突，必须找到一组"权衡解"（Pareto前沿），让决策者根据具体应用场景选择。

### 1.3 为什么选量子退火？

量子退火（Quantum Annealing, QA）天然适合求解**二次无约束二进制优化（QUBO）**问题。我们的成分优化问题可以精确编码为 QUBO 形式，利用量子隧穿效应跳出经典局部最优，在巨大离散空间中高效搜索。

## 三、编码层：PrecisionSplit 分层精度二进制编码

### 3.1 设计动机

**核心矛盾**：C 元素的含量范围（0~1.5 at%）与其他主元（15~25 at%）相差 1~2 个数量级。

如果统一编码精度：
- 若用 7 比特编码 C（步长 0.25%），则 C 的取值范围是 0~31.75%，严重超出物理合理范围，浪费比特
- 若用 3 比特编码主元（步长 0.25%），则主元范围仅 0~1.75%，完全不够用

**PrecisionSplit 的核心思想**：不同元素根据其物理含量范围分配不同数量的比特，但保持统一的步长（0.25%），确保成分和=100%在数学上可精确满足。

### 3.2 主元编码（Al, Co, Cr, Fe, Ni）

每种主元分配 **7 个二元变量**（比特）：

```
c_i = 5.0% + 0.25% × Σ_{j=0}^{6} 2^j × b_{i,j}
```

- `base_main = 5.0%`：最低成分，防止元素缺失导致相不稳定
- `step_main = 0.25%`：步长
- **取值范围**：`c_i ∈ [5.0%, 36.75%]`，共 128 个离散等级
- 等原子比（20%）落在中间区域，编码对称性好

> 上限 36.75% 略超 HEA 传统定义 35%，后处理层对 c_i > 35% 自动标记 ⚠️

### 3.3 间隙元素 C 编码

C 分配 **3 个二元变量**：

```
c_C = 0.0% + 0.25% × Σ_{j=0}^{2} 2^j × b_{C,j}
```

- `base_C = 0.0%`
- `step_C = 0.25%`（与主元统一步长）
- **取值范围**：`c_C ∈ [0.0%, 1.75%]`，共 8 个离散等级
- 1.75% 上限覆盖 C 的固溶极限及轻度碳化物形成区

### 3.4 变量汇总与映射

| 元素组 | 元素数 | 每元素比特 | 小计 |
|--------|--------|-----------|------|
| 主元 | 5 | 7 | **35** |
| C | 1 | 3 | **3** |
| **总计** | **6** | — | **38 个二元变量** |

**变量映射**：
```
x_0  ~ x_6   → Al: b_0 ~ b_6
x_7  ~ x_13  → Co: b_0 ~ b_6
x_14 ~ x_20  → Cr: b_0 ~ b_6
x_21 ~ x_27  → Fe: b_0 ~ b_6
x_28 ~ x_34  → Ni: b_0 ~ b_6
x_35 ~ x_37  → C:  b_0 ~ b_2
```

### 3.5 成分和=100%的数学可精确满足性

所有成分均为 0.25% 的整数倍。设各元素编码值为 k_i（主元）和 k_C（C）：

```
总成分 = 5×5.0% + 0.25% × (Σk_i + k_C) = 25% + 0.25% × K
```

要精确等于 100%，需 K = 300。主元 k_i ∈ [0,127]，C 的 k_C ∈ [0,7]，最大可达 5×127+7=642 > 300，最小为 0，因此 **K=300 完全可达**。

例如等原子比成分：各主元 k_i=60、C 的 k_C=0，即 60×5+0=300，对应各主元 20%、C 为 0%，均为 0.25% 的整数倍。

**编码空间中存在大量精确满足成分和=100%的整数组合，QUBO 硬约束在数学上可精确满足。**

## 四、优化层：三目标 Pareto 优化 + PenaltyFlex 自适应惩罚

### 4.1 目标函数设计

| 目标 | 符号 | 优化方向 | 物理意义 | 典型范围 | QUBO 可实现性 |
|------|------|---------|---------|----------|-------------|
| **f₁** | 混合焓代理 | 最小化 | 合金热力学稳定性（ 近似） | −20 ~ +5 kJ/mol | **✅ 天然二次型**（Miedema 模型） |
| **f₂** | 密度 | 最小化 | 合金宏观物理性质 | 6.0 ~ 9.0 g/cm³ | **✅ 线性→可构造二次型**（Vegard 定律） |
| **f₃** | 成本 | 最小化 | 元素稀缺性与市场价格 | 依赖权重 | **✅ 纯线性** |

**目标归一化**（物理先验）：

```
f₁^norm = f₁ / 30    //  范围 ~30 kJ/mol → [−0.67, 0.17]
f₂^norm = f₂ / 10    // 密度范围 ~4-10 g/cm³ → [0.6, 0.9]
f₃^norm = f₃ / c_max // c_max 预计算，→ [0, 1]
```

QUBO 中实际最小化：
```
H_obj = w₁·f₁^norm + w₂·f₂^norm + w₃·f₃^norm
```

#### f₁：混合焓代理（Miedema 模型）

```
 = ^substitutional + ΔH_C^interstitial

// 置换式主元混合焓
^substitutional = 4 Σ_{i<j, i,j∈{Al,Co,Cr,Fe,Ni}} ΔH_{ij}^{AB} · c_i · c_j

// 间隙 C 的有效混合焓（折扣因子处理）
ΔH_C^interstitial = 4 Σ_{i∈{Al,Co,Cr,Fe,Ni}} γ · ΔH_{i,C}^{Miedema} · c_i · c_C
γ = 0.2~0.3  // 唯象折扣因子：间隙占位使有效混合焓仅为置换混合的分数
```

- 天然为 QUBO 二次型，无需近似或辅助变量
- 优化方向：最小化（使  更负，合金更稳定）
- **C 的折扣处理**：间隙 C 不占据置换位，正规溶液模型对其过估。γ=0.2~0.3 为经验近似

> **简化假设**：f₁ 仅优化 （焓项），忽略 ΔS_mix（熵项）。高温（>1000°C）时 T·ΔS_mix ≈ 17.4 kJ/mol 与  同量级，完整判据应为 ΔG_mix =  − T·ΔS_mix。此简化在低温/室温场景下合理，高温场景通过后处理 Ω 判据兜底验证。

#### f₂：密度（Vegard 定律）

```
ρ = Σ_{i∈{Al,Co,Cr,Fe,Ni,C}} c_i · ρ_i
```

| 元素 | 纯元素密度 ρ_i (g/cm³) |
|------|------------------------|
| Al | 2.70 |
| Co | 8.86 |
| Cr | 7.19 |
| Fe | 7.87 |
| Ni | 8.91 |
| C | 2.27 |

等原子比 AlCoCrFeNi 预测密度 ≈ **7.11 g/cm³**。

**QUBO 嵌入**：纯线性，最小化方向。不预设固定 ρ_target，让 Pareto 前沿自然涌现密度梯度。

#### f₃：成本指数

```
f_cost = Σ w_k · c_k
```

| 元素 | 参考价格 ($/kg) | 相对权重 w_k |
|:----:|:---------------:|:------------:|
| Co | ~50 | **100** |
| Ni | ~20 | **40** |
| Cr | ~15 | **30** |
| Al | ~3 | **6** |
| Fe | ~1 | **2** |
| C | ~1 | **2** |

纯线性项，直接映射为 QUBO 的 h_i 偏置场。

### 4.2 约束处理与惩罚项设计

#### P0 硬约束：成分和 = 100%（含 C）

**惩罚项形式**：
```
H_sum = λ_sum × ( Σ c_k − 100 )²
```

**量级归一化**：为避免惩罚项系数与 （kJ/mol 量级）相差过大，对 S_var 做无量纲化处理：

```
S_var' = S_var / 75  // 归一化
H_penalty = λ_sum × (S_var' − 1)²
```

归一化后惩罚项系数与目标函数处于同一数量级，避免量子退火器动态范围溢出。

**关键设计决策**：成分和=100%是**质量守恒律（Hard Constraint）**，不是可权衡的偏好。守恒律理论上 λ_sum 只应增大不应减小，否则会出现"目标函数收益 > 守恒约束损失"的物理违规。据此将 P0 从 PenaltyFlex 剥离，**固定为常数 λ_sum = 10~20**，PenaltyFlex 仅自适应 P1/P2 的 λ。

#### P1 软约束：碳化物抑制

**核心物理**：AlCoCrFeNi-C 体系中，C > 1.0 at% 时易析出 M₂₃C₆ 或 M₇C₃ 碳化物，破坏固溶体结构。

```
H_carbide = (c_C − 0.8%)²  // 软上限 0.8 at%（保守固溶区）
```

> 原方案使用 `max(0, c_C − 0.8%)²`（分段函数），但 3 比特 QUBO 无法精确表示 8 点分段函数（7 自由度 < 8 约束条件），在 c_C=1.75% 时误差达 27.7%。改用纯二次型 `(c_C − 0.8%)²` 可**精确嵌入 QUBO**。
>
> 代价：二次型在 c_C < 0.8% 时引入额外正惩罚（将优化器推向 c_C ≈ 0.8% 而非 c_C ≈ 0），但该额外惩罚量级（0.09~0.64）远小于 P0 硬约束的典型惩罚（λ_sum=10~20 时 >10），且低 C 成分在  中本身有利，优化器仍能在 Pareto 前沿上找到 c_C < 0.8% 的有效解。

权重：`ω_carbide = 0.1~0.3`，可调。

#### P2 软约束：C-Cr 耦合最小化

**核心物理**：P1 约束仅抑制 C 的绝对含量，但碳化物形成本质是**C 与 Cr 的协同效应**。AlCoCrFeNi-C 体系中，ΔH_{Cr,C} ≈ −61 kJ/mol 为最强负混合焓对，即使 c_C < 0.8%，若 c_Cr 同时偏高，碳化物析出倾向仍然显著。

**QUBO 形式**（纯二次型，精确嵌入，以百分比为单位）：
```
H_CCr = c_C × c_Cr / H_max     // 归一化到 [0,1]
H_max = c_C^{max} × c_Cr^{max} = 1.75 × 36.75 = 64.3125    // (%²)
```

展开后：
```
H_CCr = 0.01944 × Σ_{k=0}^{2} 2^k x_{35+k}                          // 线性项(h_i)
      + 0.000972 × Σ_{k=0}^{2} Σ_{j=0}^{6} 2^{k+j} x_{35+k} x_{14+j}  // 二次交叉项(Q_ij)
```

权重：`ω_CCr = 0.3~1.0`，推荐默认值 **0.5**。

> **与 P1 H_carbide 的分工**：
> - **P1 H_carbide = (c_C − 0.8%)²**：抑制 C 的**绝对含量**（单一元素上限），对"高 C 低 Cr"场景敏感
> - **P2 H_CCr = c_C × c_Cr / 64.3125**：抑制 C 与 Cr 的**协同效应**（二元耦合），对"中 C 高 Cr"场景敏感
> - 两者正交互补，覆盖碳化物风险的全谱

#### VEC 后处理探针（已移出 QUBO 约束）

**VEC（价电子浓度）**——仅针对置换式主元：
```
VEC = Σ_{i∈{Al,Co,Cr,Fe,Ni}} c_i' · VEC_i
VEC_i: Al=3, Co=9, Cr=6, Fe=8, Ni=10
c_i' = c_i / (1 − c_C)  // 主元归一化（扣除 C 的间隙占比）
```

> **VEC 物理说明**：C 为间隙原子，不占据晶格置换位，依据 Guo et al. (2011) 与 Yang et al. (2020) 的原始定义，VEC 仅统计置换式主元。主元成分需归一化以保证 VEC 反映真实晶格电子结构。

VEC 不再嵌入 QUBO 惩罚项，仅在第 7 节后处理中作为**相结构风险提示**使用（目标区间 7.0~7.6，中心点 7.2 对应 5 主元等原子比）。

### 4.3 PenaltyFlex：反馈驱动的惩罚自适应

**核心思想**：惩罚项系数根据**当前解的质量反馈**和**用户对不同约束的偏好权重**动态调整。经典-量子混合迭代：量子退火器负责单次 QUBO 采样，经典后处理层分析结果并调整下一轮参数，再通过 kaiwu SDK 重新提交。

**分层约束优先级**：

| 约束层级 | 约束内容 | 惩罚系数 | 物理意义 |
|---------|---------|----------|---------|
| **P0（刚性）** | 成分和 = 100% | **λ_sum = 10~20（固定常数）** | 质量守恒律，不可权衡 |
| **P1（强偏好）** | 碳化物抑制（C 含量上限） | λ_carbide：PenaltyFlex 自适应 | 防止间隙 C 过量析出碳化物 |
| **P2（弱偏好）** | C-Cr 耦合最小化 | λ_CCr：PenaltyFlex 自适应 | 抑制 C-Cr 协同碳化物形成 |

**总惩罚项**：
```
H_total = H_obj + λ_sum_fixed·H_sum + ω_carbide·λ_carbide·H_carbide + ω_CCr·λ_CCr·H_CCr
```

**自适应更新规则**（仅适用于 carbide, CCr）：

每轮量子采样后，经典层分析 TOP-K 解的（目标值，约束违反度），按以下规则调整 λ：

| 反馈模式 | 判定条件 | 自适应动作 | 目的 |
|---------|---------|-----------|------|
| **探索奖励** | 最优解约束违反 > 5% 但目标值极优 | 维持或降低该约束的 λ | 给优秀方向更多空间 |
| **收紧信号** | 所有 TOP 解约束满足但目标平庸 | 增大 λ_push | 迫使跳出舒适区 |
| **边界聚焦** | Pareto 前沿恰在约束边界上 | 微调 λ 使前沿分辨率提高 | 获取更密的 Pareto 点 |
| **振荡抑制** | λ 连续两轮反向调整 | 改用几何平均而非算术更新 | 防止 hunting |

**更新公式**（仅适用于 carbide, CCr）：
```
λ_j^(t+1) = λ_j^(t) × exp( α · tanh(v̄_j − ε_j) )    j ∈ {carbide, CCr}
```
- `v̄_j`：本轮 TOP-10 解的平均约束 j 违反度
- `ε_j`：期望偏离度（探索期 2%，固化期 0%）
- `α`：学习率（0.5~1.0）

**完整 PenaltyFlex 算法**：
```
算法：PenaltyFlex (Feedback-Driven Penalty Adaptation)
────────────────────────────────────
输入：λ_sum_fixed = 10~20  // P0 硬约束固定常数，不参与自适应
      初始 λ_soft⁽⁰⁾ = (0.05, 0.05)  // (carbide, CCr)，非零初值避免乘性死锁
      α_add = 0.5, α = 0.8, γ = 0.1, T_max = 15
      偏好权重 ω = (ω_carbide, ω_CCr)
      加性启动轮数 T_add = 2
输出：优化解 x*，自适应 λ_soft*，收敛历史

1. FOR t = 1, ..., T_max:
2.     组装 QUBO：
        H = H_obj + λ_sum_fixed·H_sum + ω_carbide·λ_carbide⁽ᵗ⁾·H_carbide + ω_CCr·λ_CCr⁽ᵗ⁾·H_CCr
3.     量子求解：solutions = kaiwu.solve(H)
4.     TOP-10 解解码：{(c_k, v_k)}，v_k = 约束违反度
5.     目标值评估：f_k = (f₁(c_k), f₂(c_k), f₃(c_k))
6.     
7.     FOR 每个约束 j ∈ {carbide, CCr}:  // P0 已固定，不参与自适应
8.         v̄_j = MEAN(v_j for k=1..10)
9.         ELIF t ≤ T_add:
10.            λ_j^(t+1) = λ_j^(t) + α_add · v̄_j   // 加性启动阶段优先
11.        ELIF t > 1 AND λ_j⁽ᵗ⁻¹⁾ ≠ λ_j⁽ᵗ⁻²⁾ 
12.                 AND sign(λ_j⁽ᵗ⁾ − λ_j⁽ᵗ⁻¹⁾) ≠ sign(λ_j⁽ᵗ⁻¹⁾ − λ_j⁽ᵗ⁻²⁾):
13.            λ_j⁽ᵗ⁺¹⁾ = √(λ_j⁽ᵗ⁾ · λ_j⁽ᵗ⁻¹⁾)  // 几何平均抑制振荡
14.        ELSE:
15.            λ_j^(t+1) = λ_j^(t) × exp( α · tanh(v̄_j − ε_j) )   // 乘性演化阶段
15.   
16.    IF MAX_j |λ_j⁽ᵗ⁺¹⁾ − λ_j⁽ᵗ⁾| / λ_j⁽ᵗ⁾ < γ AND t > T_add:
17.        BREAK  // 收敛
18. RETURN best_solution, λ_soft_final
```

**warm-start 复用**：相邻权重组合的 Pareto 解通常接近，复用上一轮最优解作为初态。自适应 λ_soft 序列只需在第一组权重完整跑一遍，后续权重继承最终 λ_soft 值作为起点。λ_sum_fixed 在所有权重组合中保持恒定。

## 五、探索层：ParetoZoom 动态前沿探索

### 5.1 理论背景

固定权重网格局限：
- **非凸前沿遗漏**：weighted-sum 只能恢复凸包，凹陷区域需特定权重采样
- **均匀采样浪费**：平坦区过度采样，热点区不足
- **无反馈终止**：必须跑完全部预设权重

ParetoZoom 优势：
- kaiwu SDK 单次求解毫秒级，动态增删权重组合在 wall-clock 上完全可行
- 超体积（HV）作为统一收敛指标，同时惩罚收敛不足和分布不均

### 5.2 粗网格初始化（12 组）

启动权重集合 G_init 覆盖权重单纯形的顶点与边中点：

| 编号 | w₁ (混合焓) | w₂ (密度) | w₃ (成本) | 物理意义 |
|------|------------|----------|----------|---------|
| G1 | 1.0 | 0.0 | 0.0 | 纯混合焓优先 |
| G2 | 0.0 | 1.0 | 0.0 | 纯密度优先 |
| G3 | 0.0 | 0.0 | 1.0 | 纯成本优先 |
| G4 | 0.5 | 0.5 | 0.0 | 混合焓-密度权衡 |
| G5 | 0.5 | 0.0 | 0.5 | 混合焓-成本权衡 |
| G6 | 0.0 | 0.5 | 0.5 | 密度-成本权衡 |
| G7 | 0.33 | 0.33 | 0.33 | 三目标均衡（中心点） |
| G8 | 0.7 | 0.2 | 0.1 | 混合焓强+密度次 |
| G9 | 0.2 | 0.7 | 0.1 | 密度强+混合焓次 |
| G10 | 0.2 | 0.1 | 0.7 | 成本强+混合焓次 |
| G11 | 0.1 | 0.7 | 0.2 | 密度强+成本次 |
| G12 | 0.1 | 0.2 | 0.7 | 成本强+密度次 |

对每组权重：
1. 用 PenaltyFlex 跑完整自适应 λ 序列，获取最优可行解
2. 解码并计算 (f₁, f₂, f₃)
3. 送入 Pareto 存档 P，执行非支配筛选

**粗网格后凸性检验**：
```
CONVEXITY_TEST_3D(P₀):
    nonconvex_max ← 0
    projections ← {
        (f₁,f₂): sort_by=f₁,
        (f₁,f₃): sort_by=f₁,
        (f₂,f₃): sort_by=f₂
    }
    FOR each (plane, sort_by) in projections:
        P_proj ← 投影到 plane 的非支配解集合
        count ← 0
        按 sort_by 排序 P_proj
        FOR 每三个相邻解 (yᵢ₋₁, yᵢ, yᵢ₊₁):
            IF cross_product < 0:  // 非凸（凹陷）
                count ← count + 1
        ratio ← count / |P_proj|
        nonconvex_max ← MAX(nonconvex_max, ratio)
    RETURN nonconvex_max  // 最坏平面的非凸比例
```

若 nonconvex_max > 10%，建议切换为 ε-约束法或切比雪夫标量化。

### 5.3 ParetoZoom 算法

```
算法：Hypervolume-Guided Pareto Exploration (ParetoZoom)
────────────────────────────────────
输入：粗网格存档 P₀
      参考点 r = (max f₁ + δ₁, max f₂ + δ₂, max f₃ + δ₃)，δ_i = 10% × (max f_i − min f_i)
      ε_HV = 1%, d_threshold = 0.15·max_edge_length(P)
      σ = 0.08, T_max = 5 轮, num_reads = 1000
输出：近似 Pareto 前沿 P*

1. P ← P₀, G ← G_init
2. FOR t = 1, ..., T_max:
3.    G_new ← ∅
4.    
5.    // 阶段 A：间隙检测与加密
6.    SORT P by f₁
7.    FOR 存档 P 中每对相邻非支配解 (y_i, y_{i+1}):
8.        d_obj ← ||y_i − y_{i+1}||₂
9.        IF d_obj > d_threshold:
10.           w_mid ← interpolate_weights(y_i, y_{i+1})
11.           G_new ← G_new ∪ {w_mid}
12.   
13.   // 阶段 B：HV 热点导向微扰
14.   FOR 每个已探索权重 w ∈ G:
15.       P_wo ← P \ {w 产生的解}
16.       contribution ← HV(P, r) − HV(P_wo, r)
17.       IF contribution > 0.2 × mean_contributions:
18.           FOR k = 1, 2:
19.               w_perturb ← w + N(0, σ·I)
20.               PROJECT w_perturb onto simplex  // Σwᵢ=1, wᵢ≥0
21.               G_new ← G_new ∪ {w_perturb}
22.   
23.   // 阶段 C：去重与边界保护
24.   G_new ← DEDUPLICATE(G_new, tol=0.05)
25.   REMOVE w from G_new if ANY(wᵢ < 0.02)
26.   IF G_new = ∅: BREAK
27.   
28.   // 阶段 D：量子求解与存档更新
29.   FOR w ∈ G_new:
30.       H_single ← w₁·f₁^norm + w₂·f₂^norm + w₃·f₃^norm + H_penalty(λ_PenaltyFlex_final)
31.       solutions ← kaiwu.solve(H_single, num_reads=1000)
32.       FOR sol ∈ TOP-20(solutions):
33.           c ← decode(sol)
34.           IF constraints_satisfied(c, tol=2%):
35.               y ← (f₁(c), f₂(c), f₃(c))
36.               P ← nondominated_update(P, y)
37.   
38.   // 阶段 E：HV 收敛判定
39.   HV⁽ᵗ⁾ ← HV(P, r)
40.   IF |HV⁽ᵗ⁾ − HV⁽ᵗ⁻¹⁾| / HV⁽ᵗ⁾ < ε_HV: BREAK
41. 
42. RETURN P
```

### 5.4 双层自适应架构

| 层次 | 算法 | 控制对象 | 作用域 |
|------|------|---------|--------|
| **外层 ParetoZoom** | 5.3 节 | 权重 (w₁,w₂,w₃) | **Pareto 前沿质量**（覆盖度、密度） |
| **内层 PenaltyFlex** | 4.3 节 | 惩罚系数 λ_carbide, λ_CCr（λ_sum=10~20 固定） | **约束满足率**（可行性、精确度） |

**协同流程**：
1. ParetoZoom 提出新权重 `w_new`
2. 查找最近邻 `w_neighbor`（已跑过 PenaltyFlex）
3. 以 `w_neighbor` 的 PenaltyFlex 终值 `λ*` 为 `w_new` 的初值（warm-start）
4. PenaltyFlex 跑自适应 λ 序列，微调至 `λ_new*`
5. `λ_new*` 存入缓存，供后续相邻权重复用

### 5.5 理论预期

| 特性 | 预期 |
|------|------|
| 粗网格调用 | 12 组 QUBO，每组 PenaltyFlex≈10-15 轮 → 总计 120-180 次量子提交 |
| ParetoZoom 迭代 | 每轮新增 3-8 组权重，2-4 轮收敛 → 总计 20-40 次量子提交 |
