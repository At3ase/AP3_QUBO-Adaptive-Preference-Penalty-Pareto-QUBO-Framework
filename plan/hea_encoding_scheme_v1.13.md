## 一、体系特征分析

| 元素 | 角色 | 典型含量范围 | 精度要求 |
|------|------|-------------|---------|
| Al | 主元 | 15~25 at% | 中等 |
| Co | 主元 | 15~25 at% | 中等 |
| Cr | 主元 | 15~25 at% | 中等 |
| Fe | 主元 | 15~25 at% | 中等 |
| Ni | 主元 | 15~25 at% | 中等 |
| C  | 间隙元素 | 0~1.5 at% | **高** |

**关键洞察**：C与其他主元含量差1~2个数量级。统一编码精度会导致主元比特数爆炸或C精度不足。采用**分层精度二进制编码（PrecisionSplit）**解决。

## 二、分层精度二进制编码（PrecisionSplit）

### 2.1 主元编码（Al, Co, Cr, Fe, Ni）

每种主元分配 **7个二元变量**：

```
b_{i,0}, b_{i,1}, ..., b_{i,6}  ∈ {0,1}
```

**解码公式**：
```
c_i = base_main + step_main × Σ_{j=0}^{6} 2^j × b_{i,j}
```

**参数**：
- `base_main = 5.0%`（最低成分，防止元素缺失导致相不稳定。上限36.75%略超HEA传统定义35%，后处理§7对c_i>35%自动标记⚠️）
- `step_main = 0.25%`（步长）
- **取值范围**：`c_i ∈ [5.0%, 36.75%]`，共128个离散等级

> 等原子比（20%）落在中间区域，编码对称性好。

### 2.2 间隙元素C编码

C分配 **3个二元变量**：

```
b_{C,0}, b_{C,1}, b_{C,2} ∈ {0,1}
```

**解码公式**：
```
c_C = base_C + step_C × Σ_{j=0}^{2} 2^j × b_{C,j}
```

**参数**：
- `base_C = 0.0%`
- `step_C = 0.25%`（与主元统一步长）
- **取值范围**：`c_C ∈ [0.0%, 1.75%]`，共8个离散等级

> 1.75%上限覆盖C的固溶极限及轻度碳化物形成区。如需更高可调为4比特。

### 2.3 变量汇总

| 元素组 | 元素数 | 每元素比特 | 小计 |
|--------|--------|-----------|------|
| 主元 | 5 | 7 | **35** |
| C | 1 | 3 | **3** |
| **总计** | **6** | — | **38 个二元变量** |

> **分层编码保留**：主元范围大→7比特，C范围小→3比特。步长统一为0.25%确保数学上可精确满足成分和=100%。

### 2.4 变量映射

```
x_0  ~ x_6   → Al: b_0 ~ b_6
x_7  ~ x_13  → Co: b_0 ~ b_6
x_14 ~ x_20  → Cr: b_0 ~ b_6
x_21 ~ x_27  → Fe: b_0 ~ b_6
x_28 ~ x_34  → Ni: b_0 ~ b_6
x_35 ~ x_37  → C:  b_0 ~ b_2
```

### 2.5 成分解码的线性表达式

```
c_Al = 5.0 + 0.25×(x_0 + 2x_1 + 4x_2 + 8x_3 + 16x_4 + 32x_5 + 64x_6)
c_Co = 5.0 + 0.25×(x_7 + 2x_8 + 4x_9 + 8x_10 + 16x_11 + 32x_12 + 64x_13)
c_Cr = 5.0 + 0.25×(x_14 + 2x_15 + 4x_16 + 8x_17 + 16x_18 + 32x_19 + 64x_20)
c_Fe = 5.0 + 0.25×(x_21 + 2x_22 + 4x_23 + 8x_24 + 16x_25 + 32x_26 + 64x_27)
c_Ni = 5.0 + 0.25×(x_28 + 2x_29 + 4x_30 + 8x_31 + 16x_32 + 32x_33 + 64x_34)
c_C  = 0.0 + 0.25×(x_35 + 2x_36 + 4x_37)
```

**统一步长验证**：
所有成分均为 0.25% 的整数倍。设各元素编码值为 k_i（主元）和 k_C（C）：
```
总成分 = 5×5.0% + 0.25% × (Σk_i + k_C) = 25% + 0.25% × K
```
要精确等于100%，需 K = 300。主元 k_i ∈ [0,127]，C 的 k_C ∈ [0,7]，最大可达 5×127+7=642 > 300，最小为0，因此 **K=300 完全可达**（例如等原子比成分：各主元 k_i=60、C 的 k_C=0，即 60×5+0=300，对应各主元 20%、C 为 0%，均为 0.25% 的整数倍）。编码空间中存在大量精确满足成分和=100%的整数组合，QUBO硬约束在数学上**可精确满足**。

> **非零C时的等原子比限制（v1.12补充）**：当 c_C > 0 时，5主元严格等原子比需满足 Σk_i = 300 − k_C 且 k_i 全部相等，即 (300 − k_C) 必须是5的倍数。k_C ∈ {0,7} 中仅 k_C=0 满足（对应 c_C=0%），另一解 k_C=5（对应 c_C=1.25%）也可实现等原子比。其他 C 含量时主元必须不等比——这不是方案缺陷，而是成分和硬约束与离散编码的自然结果，优化器可自然处理。

## 三、约束处理与惩罚项设计

### 3.1 硬约束：成分和 = 100%（含C）

六种元素（Al, Co, Cr, Fe, Ni, C）的原子百分比之和严格等于100%。C虽为间隙元素且含量低，但在约束方程中占据完整权重。

**惩罚项形式**：
```
H_sum = λ_sum × ( Σ_{k∈{Al,Co,Cr,Fe,Ni,C}} c_k − 100 )²
```

展开为QUBO：

定义 `S = Σ c_k = Σ(base_k) + Σ(step_k × Σ 2^j x_{k,j})`

常数基线：`S_const = 5×5.0 + 0.0 = 25.0%`（主元最低值之和）

变量部分：`S_var = S − S_const`

**量级归一化**：为避免惩罚项系数与ΔH_mix（kJ/mol量级）相差过大，对S_var做无量纲化处理：
```
S_var' = S_var / 75  // 归一化

// 分母75的推导：S_var = 总成分 − 基线 = 100% − 5×5.0% = 75%（等原子比目标值）
// S_var = 0.25% × K, K ∈ [0, 642], 故 S_var ∈ [0, 160.5]（百分比单位）
// S_var' = S_var / 75 ∈ [0, 2.14]，等原子比（K=300）时 S_var'=1，惩罚=0

H_penalty = λ_sum × (S_var' − 1)²
          = λ_sum × [(S_var/75) − 1]²
          = λ_sum × [S_var²/5625 − 2·S_var/75 + 1]
          = (λ_sum/5625) × [S_var² − 150·S_var + 5625]
```

归一化后惩罚项系数与目标函数处于同一数量级，避免量子退火器动态范围溢出。
数值验证：
- K=300（等原子比）: S_var=75, S_var'=1.00, (S_var'−1)²=0 ✅
- K=0（全最低）: S_var=0, S_var'=0.00, (S_var'−1)²=1.00
- K=642（全最高）: S_var=160.5, S_var'=2.14, (S_var'−1)²=1.30

其中 `S_var²` 展开后：
- 自平方项：`x_i² = x_i`（二元变量）→ 线性项，系数 = (λ_sum/5625) × coef_i
- 交叉项：`2×coef_i×coef_j×x_i×x_j` → QUBO二次项，系数 = (λ_sum/5625) × 2×coef_i×coef_j

### 3.2 Feedback-Driven Penalty Adaptation (PenaltyFlex)

**核心思想**：惩罚项系数根据**当前解的质量反馈**和**用户对不同约束的偏好权重**动态调整。经典-量子混合迭代：量子退火器负责单次QUBO采样，经典后处理层分析结果并调整下一轮参数，再通过kaiwu SDK重新提交。

#### 3.2.1 分层约束优先级

| 约束层级 | 约束内容 | 惩罚系数 | 物理意义 |
|---------|---------|----------|---------|
| **P0（刚性）** | 成分和 = 100% | **λ_sum = 10~20（固定常数）** | 质量守恒律，不可权衡 |
| **P1（强偏好）** | 碳化物抑制（C含量上限） | λ_carbide：PenaltyFlex自适应 | 防止间隙C过量析出碳化物 |
| **P2（弱偏好）** | C-Cr耦合最小化 | λ_CCr：PenaltyFlex自适应 | 抑制C-Cr协同碳化物形成 |

> **P0剥离说明**（v1.9重要修正）：成分和=100%是**质量守恒律（Hard Constraint）**，不是可权衡的偏好。守恒律理论上λ_sum只应增大不应减小，否则会出現"目标函数收益 > 守恒约束损失"的物理违规。据此将P0从PenaltyFlex剥离，固定为常数λ_sum = 10~20，PenaltyFlex仅自适应P1/P2的λ。

> **VEC约束移除说明**：原方案将VEC（价电子浓度）作为P1软约束嵌入QUBO，但VEC与f₁的ΔH_mix在物理上存在耦合（如VEC降低常伴随d电子数减少，影响混合焓），导致QUBO内部隐性对抗。现依据评审建议，**VEC仅作为后处理相结构探针**（见第7节物理过滤器），不再参与QUBO惩罚项，避免与f₁目标函数冲突。

总惩罚项（P0硬约束 + P1/P2软约束）：
```
H_total = H_obj + λ_sum_fixed·H_sum + ω_carbide·λ_carbide·H_carbide + ω_CCr·λ_CCr·H_CCr

// λ_sum_fixed = 10~20（固定常数，不参与自适应）
// λ_carbide, λ_CCr 由 PenaltyFlex 自适应控制
```

#### 3.2.2 P1约束：碳化物抑制项

**核心物理**：AlCoCrFeNi-C体系中，C > 1.0 at% 时易析出M₂₃C₆或M₇C₃碳化物（Gorr et al., 2015），破坏固溶体结构。将碳化物抑制作为P1软约束，引导优化器向低C固溶区探索。

```
H_carbide = (c_C − 0.8%)²  // 软上限0.8 at%（保守固溶区）
```

> **QUBO可实现性说明**：原方案使用 `max(0, c_C − 0.8%)²`（分段函数），但数学验证表明3比特QUBO无法精确表示8点分段函数（7自由度 < 8约束条件），在c_C=1.75%时误差达27.7%。改用纯二次型 `(c_C − 0.8%)²` 可**精确嵌入QUBO**。
> 
> **代价与补偿**：`(c_C − 0.8%)²` 相对于原始分段函数 `max(0, c_C − 0.8%)²` 的额外惩罚：
> | c_C | 分段函数惩罚 | 二次型惩罚 | 额外惩罚 |
> |-----|-------------|-----------|---------|
> | 0% | 0 | 0.64 | **+0.64** |
> | 0.5% | 0 | 0.09 | **+0.09** |
> | 0.8% | 0 | 0 | 0 |
> | 1.75% | 0.9025 | 0.9025 | 0 |
> 
> 二次型在 c_C < 0.8% 时引入额外正惩罚（将优化器推向 c_C ≈ 0.8% 而非 c_C ≈ 0），这是**QUBO可实现的代价**。但由于该额外惩罚量级（0.09~0.64）远小于P0硬约束的典型惩罚（λ_sum=10~20时 >10），且低C成分在ΔH_mix中本身有利（C-TM强负混合焓），优化器仍能在Pareto前沿上找到 c_C < 0.8% 的有效解。

权重：`ω_carbide = 0.1~0.3`，可调。

> **与后处理VEC探针的分工**：
> - **P1 H_carbide**：参与QUBO优化，主动抑制高C成分
> - **后处理VEC检查**（第7节）：优化完成后独立验证相结构，不参与QUBO，避免与f₁冲突


#### 3.2.3 P2约束：C-Cr耦合最小化

**核心物理**：P1约束仅抑制C的绝对含量（c_C ≤ 0.8%），但碳化物形成本质是**C与Cr的协同效应**。AlCoCrFeNi-C体系中，ΔH_{Cr,C} ≈ −61 kJ/mol 为最强负混合焓对，即使 c_C < 0.8%，若 c_Cr 同时偏高，碳化物析出倾向仍然显著。P2约束通过最小化 c_C × c_Cr 乘积，从**二元耦合角度**补充P1的盲区。

**QUBO形式**（纯二次型，精确嵌入，以百分比为单位）：
```
H_CCr = c_C × c_Cr / H_max     // 归一化到[0,1]

H_max = c_C^{max} × c_Cr^{max} = 1.75 × 36.75 = 64.3125    // (%²)
```

> **单位说明**：c_C 和 c_Cr 均以百分比数值（不含%号）代入，H_max 单位为 %²。例如 c_C=0.5% 时代入数值 0.5。

**展开验证**：
- c_C = 0.25 × Σ_{k=0}^{2} 2^k · x_{35+k}    ∈ [0, 1.75]  （3比特：x₃₅~x₃₇）
- c_Cr = 5.0 + 0.25 × Σ_{j=0}^{6} 2^j · x_{14+j}  ∈ [5.0, 36.75]  （7比特：x₁₄~x₂₀）

展开 c_C × c_Cr：
```
c_C × c_Cr = [0.25·Σ(2^k x_{35+k})] × [5.0 + 0.25·Σ(2^j x_{14+j})]
           = 1.25·Σ(2^k x_{35+k}) + 0.0625·ΣΣ(2^{k+j} x_{35+k} x_{14+j})
```

归一化后（除以 H_max = 64.3125）：
```
H_CCr = 0.01944 × Σ_{k=0}^{2} 2^k x_{35+k}                          // 线性项(h_i)
      + 0.000972 × Σ_{k=0}^{2} Σ_{j=0}^{6} 2^{k+j} x_{35+k} x_{14+j}  // 二次交叉项(Q_ij)
```

**线性项系数**：
| 变量 | 索引 | 计算过程 | 系数 |
|------|------|---------|------|
| x₃₅ (C, b₀) | h₃₅ | 1.25×1 / 64.3125 | **0.01944** |
| x₃₆ (C, b₁) | h₃₆ | 1.25×2 / 64.3125 | **0.03887** |
| x₃₇ (C, b₂) | h₃₇ | 1.25×4 / 64.3125 | **0.07775** |

**交叉项系数基数** = 0.000972（= 0.0625 / 64.3125），Q_{35+k, 14+j} = 基数 × 2^{k+j}

|  | x₁₄(Cr,b₀) | x₁₅(Cr,b₁) | x₁₆(Cr,b₂) | x₁₇(Cr,b₃) | x₁₈(Cr,b₄) | x₁₉(Cr,b₅) | x₂₀(Cr,b₆) |
|--|-----------|-----------|-----------|-----------|-----------|-----------|-----------|
| **x₃₅(C,b₀)** | 0.00097 | 0.00194 | 0.00389 | 0.00778 | 0.01555 | 0.03110 | 0.06220 |
| **x₃₆(C,b₁)** | 0.00194 | 0.00389 | 0.00778 | 0.01555 | 0.03110 | 0.06220 | 0.12439 |
| **x₃₇(C,b₂)** | 0.00389 | 0.00778 | 0.01555 | 0.03110 | 0.06220 | 0.12439 | **0.24879** |

**量级评估**：
- 最大交叉项 Q[37][20] = 0.24879
- P2最大贡献（ω_CCr=0.5, λ_CCr=1.0）：0.5 × 1.0 × 0.24879 ≈ **0.124**
- f₁^norm 典型跨度：~0.84，P2最大贡献约为 f₁ 的 **15%**
- 与f₂^norm跨度（~0.30）相比：P2约为 f₂ 的 **41%**

> **注**：正确归一化后P2约束强度低于原始设计意图（见v1.11评审反馈[C2]）。通过将 ω_CCr 从 0.1~0.3 提升至 **0.3~1.0**，可在保持与f₁/f₂可比量级的条件下确保P2的有效约束能力。

**注入位置**（Python）：
```python
# 在H_CCr前乘以外部权重
omega_CCr = 0.5   # 用户可调（0.3~1.0），推荐0.5作为默认值
lambda_CCr = PenaltyFlex输出  # 自适应

# 线性项（加到h向量）
h[35] += omega_CCr * lambda_CCr * 0.01944
h[36] += omega_CCr * lambda_CCr * 0.03887
h[37] += omega_CCr * lambda_CCr * 0.07775

# 交叉项（加到Q矩阵，仅填充C-bit × Cr-bit区域，21个非零项）
base = 0.000972 * omega_CCr * lambda_CCr
for k in range(3):       # C: x_35, x_36, x_37
    for j in range(7):   # Cr: x_14, ..., x_20
        Q[35+k][14+j] += base * (2**k) * (2**j)
```

权重：`ω_CCr = 0.3~1.0`（v1.12调整，原v1.11的0.1~0.3因归一化修正后强度不足），推荐默认值 **0.5**。

> **与P1 H_carbide的分工**：
> - **P1 H_carbide = (c_C − 0.8%)²**：抑制C的**绝对含量**（单一元素上限），对"高C低Cr"场景敏感
> - **P2 H_CCr = c_C × c_Cr / 64.3125**：抑制C与Cr的**协同效应**（二元耦合），对"中C高Cr"场景敏感
> - 两者正交互补，覆盖碳化物风险的全谱

#### 3.2.4 VEC后处理探针（已移出QUBO约束）

**VEC（价电子浓度）—— 仅针对置换式主元**：
```
VEC = Σ_{i∈{Al,Co,Cr,Fe,Ni}} c_i' · VEC_i
VEC_i: Al=3, Co=9, Cr=6, Fe=8, Ni=10

c_i' = c_i / (1 − c_C)  // 主元归一化（扣除C的间隙占比）
```

> **VEC物理说明**：C为间隙原子，不占据晶格置换位，依据Guo et al. (2011)与Yang et al. (2020)的原始定义，VEC仅统计置换式主元。主元成分需归一化以保证VEC反映真实晶格电子结构。

VEC不再嵌入QUBO惩罚项，仅在第7节后处理中作为**相结构风险提示**使用（目标区间7.0~7.6，中心点7.2对应5主元等原子比）。

#### 3.2.5 自适应更新规则（PenaltyFlex）

PenaltyFlex仅控制P1/P2的λ（carbide, CCr），P0的λ_sum为固定常数不参与自适应。

每轮量子采样后，经典层分析TOP-K解的（目标值，约束违反度），按以下规则调整λ

> **违反度定义（v1.13明确）**：
> - P1（碳化物抑制）：`v_carbide = (c_C − 0.8)²`（%²单位，范围[0, 0.90]）
> - P2（C-Cr耦合）：`v_CCr = c_C × c_Cr / 64.3125`（归一化值，范围[0, 1]）
> 两者量级均在α_add=0.5下产生合理的λ增长速率（~0.1~0.5/轮）：

| 反馈模式 | 判定条件 | 自适应动作 | 目的 |
|---------|---------|-----------|------|
| **探索奖励** | 最优解约束违反 > 5% 但目标值极优 | 维持或降低该约束的λ | 给优秀方向更多空间 |
| **收紧信号** | 所有TOP解约束满足但目标平庸 | 增大λ_push | 迫使跳出舒适区 |
| **边界聚焦** | Pareto前沿恰在约束边界上 | 微调λ使前沿分辨率提高 | 获取更密的Pareto点 |
| **振荡抑制** | λ连续两轮反向调整 | 改用几何平均而非算术更新 | 防止 hunting |

**更新公式**（仅适用于carbide, CCr）：
```
λ_j^(t+1) = λ_j^(t) × exp( α · tanh(v̄_j − ε_j) )    j ∈ {carbide, CCr}
```
- `v̄_j`：本轮TOP-10解的平均约束j违反度
- `ε_j`：期望偏离度（探索期2%，固化期0%）
- `α`：学习率（0.5~1.0）

**完整PenaltyFlex算法**：
```
算法：PenaltyFlex (Feedback-Driven Penalty Adaptation)
────────────────────────────────────
输入：λ_sum_fixed = 10~20  // P0硬约束固定常数，不参与自适应
      初始λ_soft⁽⁰⁾ = (0.05, 0.05)  // (carbide, CCr)，非零初值避免乘性死锁
      α_add = 0.5, α = 0.8, γ = 0.1, T_max = 15
      偏好权重 ω = (ω_carbide, ω_CCr)
      加性启动轮数 T_add = 2
输出：优化解 x*，自适应λ_soft*，收敛历史

1. FOR t = 1, ..., T_max:
2.     组装QUBO：
        H = H_obj + λ_sum_fixed·H_sum + ω_carbide·λ_carbide⁽ᵗ⁾·H_carbide + ω_CCr·λ_CCr⁽ᵗ⁾·H_CCr
3.     量子求解：solutions = kaiwu.solve(H)
4.     TOP-10解解码：{(c_k, v_k)}，v_k = 约束违反度
5.     目标值评估：f_k = (f₁(c_k), f₂(c_k), f₃(c_k))
6.     
7.     FOR 每个约束j ∈ {carbide, CCr}:  // P0已固定，不参与自适应
8.         v̄_j = MEAN(v_j for k=1..10)
9.         ELIF t ≤ T_add:
10.            λ_j^(t+1) = λ_j^(t) + α_add · v̄_j   // 加性启动阶段优先（避免t=2时sign(0)边界）
11.        ELIF t > 1 AND λ_j⁽ᵗ⁻¹⁾ ≠ λ_j⁽ᵗ⁻²⁾ 
12.                 AND sign(λ_j⁽ᵗ⁾ − λ_j⁽ᵗ⁻¹⁾) ≠ sign(λ_j⁽ᵗ⁻¹⁾ − λ_j⁽ᵗ⁻²⁾):
13.            λ_j⁽ᵗ⁺¹⁾ = √(λ_j⁽ᵗ⁾ · λ_j⁽ᵗ⁻¹⁾)  // 几何平均抑制振荡
14.        ELSE:
15.            λ_j^(t+1) = λ_j^(t) × exp( α · tanh(v̄_j − ε_j) )   // 乘性演化阶段
15.   
16.    IF MAX_j |λ_j⁽ᵗ⁺¹⁾ − λ_j⁽ᵗ⁾| / λ_j⁽ᵗ⁾ < γ AND t > T_add:
17.        BREAK  // 收敛（加性阶段不判定收敛）
18. RETURN best_solution, λ_soft_final
```

**warm-start复用**：相邻权重组合的Pareto解通常接近，复用上一轮最优解作为初态。自适应λ_soft序列只需在第一组权重完整跑一遍，后续权重继承最终λ_soft值作为起点。λ_sum_fixed在所有权重组合中保持恒定。

## 四、三目标Pareto优化框架

### 4.1 目标函数设计

| 目标 | 符号 | 优化方向 | 物理意义 | 典型范围 | QUBO可实现性 |
|------|------|---------|---------|----------|-------------|
| **f₁** | 混合焓代理 | 最小化 | 合金热力学稳定性（ΔH_mix近似） | −20 ~ +5 kJ/mol | **✅ 天然二次型**（Miedema模型） |
| **f₂** | 密度 | 最小化 | 合金宏观物理性质 | 6.0 ~ 9.0 g/cm³ | **✅ 线性→可构造二次型**（Vegard） |
| **f₃** | 成本 | 最小化 | 元素稀缺性与市场价格 | 依赖权重（见下） | **✅ 纯线性** |

> **目标归一化必要性**：f₁范围约25 kJ/mol，f₂范围约3 g/cm³，f₃依赖权重定义。若不加归一化，加权和 `w₁·f₁ + w₂·f₂ + w₃·f₃` 中f₁贡献将隐性主导（约8倍于f₂），导致用户期望的"50:50权衡"实际执行为"89:11"。

#### 目标归一化层（新增）

**归一化策略**：全程使用物理先验归一化（v1.8统一决策）

理由：
1. 38变量QUBO单次求解毫秒级，无需动态归一化的精度增益
2. 避免粗网格→ParetoZoom切换时PenaltyFlex λ的warm-start失效问题
3. 6元素小规模问题，物理先验已足够精确

```
f₁^norm = f₁ / 30    // ΔH_mix范围 ~30 kJ/mol → [−0.67, 0.17]
f₂^norm = f₂ / 10    // 密度范围 ~4-10 g/cm³ → [0.6, 0.9]
f₃^norm = f₃ / c_max // c_max预计算，→ [0, 1]
```

> **动态归一化**（可选增强）：粗网格完成后可切换为 `(f_i − f_i^min)/(f_i^max − f_i^min)`，
> 但需重新初始化PenaltyFlex λ为(0.05, 0.05)。对当前38变量问题增益有限。
>
> **⚠️ 权重校准说明（v1.12新增）**：三目标归一化后的实际动态范围差异显著，等权重(0.33,0.33,0.33)不意味着"同等偏好"：
> | 目标 | 归一化范围 | 等权重贡献范围 | 动态跨度 | 相对影响力 |
> |------|-----------|--------------|---------|-----------|
> | f₁^norm | [−0.67, +0.17] | [−0.22, +0.06] | **0.28** | 基准(1.0) |
> | f₂^norm | [0.60, 0.90] | [0.20, 0.30] | **0.10** | **0.36× f₁** |
> | f₃^norm | [0, 1] | [0, 0.33] | **0.33** | 1.2× f₁ |
>
> **建议权重映射**：若用户希望三者"同等重要"，建议采用校准权重 (0.50, 0.35, 0.15) 替代 naive 等权重。更一般地，建议通过粗网格Pareto前沿的初始分布来反推有效权重。

QUBO中实际最小化：
```
H_obj = w₁·f₁^norm + w₂·f₂^norm + w₃·f₃^norm
```

归一化后各目标量纲统一为O(1)量级，权重 `w₁, w₂, w₃` 反映用户真实偏好比例。

#### f₁：混合焓代理（ΔH_mix via Miedema模型）

```
ΔH_mix = ΔH_mix^substitutional + ΔH_C^interstitial

// 置换式主元混合焓
ΔH_mix^substitutional = 4 Σ_{i<j, i,j∈{Al,Co,Cr,Fe,Ni}} ΔH_{ij}^{AB} · c_i · c_j

// 间隙C的有效混合焓（折扣因子处理）
ΔH_C^interstitial = 4 Σ_{i∈{Al,Co,Cr,Fe,Ni}} γ · ΔH_{i,C}^{Miedema} · c_i · c_C
γ = 0.2~0.3  // 唯象折扣因子：间隙占位使有效混合焓仅为置换混合的分数

H_form = η_form × ΔH_mix
```
- 天然为QUBO二次型，无需近似或辅助变量
- 优化方向：最小化（使ΔH_mix更负，合金更稳定）
- η_form：缩放系数，使混合焓量级与惩罚项匹配
- **C的折扣处理**：间隙C不占据置换位，正规溶液模型对其过估。γ=0.2~0.3为经验近似，建议做敏感性分析（γ=0.1, 0.3, 0.5）

> **物理动机**：f₁中C-Cr强负混合焓（ΔH_{Cr,C} ≈ −61 kJ/mol）会驱动优化器偏好高C成分，与P1碳化物抑制约束形成QUBO内部"拔河"。γ折扣减少此对抗，提升退火效率。
>
> **简化假设说明（v1.12）**：f₁仅优化ΔH_mix（焓项），忽略ΔS_mix（熵项）。高温（>1000°C）时T·ΔS_mix ≈ 17.4 kJ/mol与ΔH_mix同量级，完整判据应为ΔG_mix = ΔH_mix − T·ΔS_mix。此简化在低温/室温场景下合理，高温场景通过后处理Ω判据（Ω = T_m·ΔS_mix/|ΔH_mix|）进行兜底验证。

> **与相稳定性的关系**：f₁直接负责热力学稳定性（ΔH_mix最小化），因此P1约束中不再重复包含ΔH_mix软引导。VEC保留为独立相结构判据。后处理层（6.3节）对极端ΔH_mix值做物理合理性检查。

#### f₂：密度（Vegard定律）

**代理模型**：Vegard定律线性近似。HEA中预测误差约0.5~1%，对成分优化足够精确。

```
ρ = Σ_{i∈{Al,Co,Cr,Fe,Ni,C}} c_i · ρ_i
```

| 元素 | 纯元素密度 ρ_i (g/cm³) |
|------|------------------------|
| Al | 2.70 |
| Co | 8.86 |
| Cr | 7.19 |
| Fe | 7.87 |
| Ni | 8.91 |
| C  | 2.27 |

等原子比AlCoCrFeNi预测密度 ≈ **7.11 g/cm³**。

**QUBO嵌入**：
```
H_density = ρ = Σ c_i · ρ_i   // 纯线性，最小化方向
```
- 不预设固定ρ_target，让Pareto前沿自然涌现密度梯度
- Al↑→密度↓，但Al↑同时导致BCC↑、韧性↓——三目标自然竞争

> **C密度近似**：ρ_C=2.27 g/cm³为石墨值。间隙C的实际密度贡献在c_C<1%时误差<0.03 g/cm³（<0.5%），与Vegard定律自身精度（0.5~1%）相当。对于本方案的优化精度需求可接受。
> 
> **替代取值（v1.12补充）**：基于间隙C在BCC/FCC金属基体中的偏摩尔体积（~5.7 Å³/atom）估算，C的有效密度贡献约 **1.8 g/cm³**（低于石墨值2.27）。两种取值在c_C<1%时导致密度预测差异<0.01 g/cm³，不影响优化方向。建议实现时以2.27为默认值，1.8为敏感性测试值。

#### f₃：成本指数

```
f_cost = Σ w_k · c_k
```
- Co权重较高（战略资源）
- Ni权重中等
- Al、Fe、C权重较低
- 纯线性项，直接映射为QUBO的h_i偏置场

### 4.2 Pareto前沿生成：Hypervolume-Guided Pareto Exploration (ParetoZoom) + 粗网格初始化

**用户确认方案2**：先以12组粗网格建立初始前沿轮廓，再由ParetoZoom动态填补间隙与热点加密。

#### 4.2.1 理论背景

固定权重网格局限：
- **非凸前沿遗漏**：weighted-sum只能恢复凸包，凹陷区域需特定权重采样
- **均匀采样浪费**：平坦区过度采样，热点区不足
- **无反馈终止**：必须跑完全部预设权重

ParetoZoom优势：
- kaiwu SDK单次求解毫秒级，动态增删权重组合在wall-clock上完全可行
- 超体积（HV）作为统一收敛指标，同时惩罚收敛不足和分布不均

#### 4.2.2 粗网格初始化（12组）

启动权重集合 `G_init` 覆盖权重单纯形的顶点与边中点：

| 编号 | w₁ (混合焓) | w₂ (密度) | w₃ (成本) | 物理意义 |
|------|------------|----------|----------|---------|
| G1 | 1.0 | 0.0 | 0.0 | 纯混合焓优先 |
| G2 | 0.0 | 1.0 | 0.0 | 纯密度优先 |
| G3 | 0.0 | 0.0 | 1.0 | 纯成本优先 |
| G4 | 0.5 | 0.5 | 0.0 | 混合焓-密度权衡 |
| G5 | 0.5 | 0.0 | 0.5 | 混合焓-成本权衡 |
| G6 | 0.0 | 0.5 | 0.5 | 密度-成本权衡 |
| G7 | 0.33 | 0.33 | 0.33 | 三目标均衡（中心点） |
| G8 | 0.7 | 0.2 | 0.1 | 混合焓强+密度次 |
| G9 | 0.2 | 0.7 | 0.1 | 密度强+混合焓次 |
| G10 | 0.2 | 0.1 | 0.7 | 成本强+混合焓次 |
| G11 | 0.1 | 0.7 | 0.2 | 密度强+成本次 |
| G12 | 0.1 | 0.2 | 0.7 | 成本强+密度次 |

> **粗网格12组设计**（v1.10增强）：原6组仅覆盖权重单纯形的顶点和边中点，HV估计在6点时不稳定（样本数过少导致方差大）。新增G7~G12覆盖**内部区域**和**非对称高权重方向**，使初始HV估计更稳健，ParetoZoom探索方向更可靠。

对每组权重：
1. 用PenaltyFlex跑完整自适应λ序列，获取最优可行解
2. 解码并计算 (f₁, f₂, f₃)
3. 送入Pareto存档P，执行非支配筛选

首轮保障：`|P| ≥ 1`，HV(P) > 0。

**粗网格后凸性检验**（新增）：
```
CONVEXITY_TEST(P₀):
    nonconvex_count ← 0
    FOR 每三个相邻非支配解 (y_{i-1}, y_i, y_{i+1}) 按f₁排序:
        // 检查 y_i 是否在 y_{i-1}→y_{i+1} 连线的"外侧"
        cross ← (y_i.f₂ − y_{i-1}.f₂) × (y_{i+1}.f₁ − y_{i-1}.f₁) − 
                 (y_i.f₁ − y_{i-1}.f₁) × (y_{i+1}.f₂ − y_{i-1}.f₂)
        IF cross < 0:  // 右手法则为负 = 非凸（凹陷）
            nonconvex_count ← nonconvex_count + 1
    
    nonconvex_ratio ← nonconvex_count / |P₀|
    IF nonconvex_ratio > 10%:
        WARNING: "Pareto前沿非凸比例{nonconvex_ratio}%，建议切换为ε-约束法或切比雪夫标量化"
        // 备选：增加中心权重 G7=(0.33,0.33,0.33) 启动非凸探测
    ELSE:
        PROCEED with ParetoZoom
```
> v1.6将VEC移出QUBO后三目标trade-off更"干净"，前沿可能接近凸。但缺乏验证即使用加权和法属系统性盲区，故增加此检验步骤。
> 
> **实现建议（v1.12更新）**：对三个投影平面（f₁-f₂, f₁-f₃, f₂-f₃）均执行凸性检验，取最坏结果作为非凸性指标。虽然f₂-f₃ trade-off较弱，但f₁-f₃方向可能存在显著非凸性，2D投影可能遗漏。
```
CONVEXITY_TEST_3D(P₀):
    nonconvex_max ← 0
    // 每个投影平面指定排序轴（用于确定"相邻"非支配解）
    projections ← {
        (f₁,f₂): sort_by=f₁,   // f₁-f₂平面按f₁排序
        (f₁,f₃): sort_by=f₁,   // f₁-f₃平面按f₁排序
        (f₂,f₃): sort_by=f₂    // f₂-f₃平面按f₂排序
    }
    FOR each (plane, sort_by) in projections:
        P_proj ← 投影到plane的非支配解集合
        // 注意：投影后|P_proj| ≥ |P₀|，原3D被支配解可能变为2D非支配
        count ← 0
        按sort_by排序P_proj
        FOR 每三个相邻解 (yᵢ₋₁, yᵢ, yᵢ₊₁):
            IF cross_product < 0:  // 非凸（凹陷）
                count ← count + 1
        ratio ← count / |P_proj|
        nonconvex_max ← MAX(nonconvex_max, ratio)
    RETURN nonconvex_max  // 最坏平面的非凸比例
```

#### 4.2.3 ParetoZoom算法

```
算法：Hypervolume-Guided Pareto Exploration (ParetoZoom)
────────────────────────────────────
输入：粗网格存档 P₀
      参考点 r = (max f₁ + δ₁, max f₂ + δ₂, max f₃ + δ₃)，δ_i = 10% × (max f_i − min f_i)
      ε_HV = 1%, d_threshold = 0.15·max_edge_length(P)
      σ = 0.08, T_max = 5轮, num_reads = 1000
输出：近似Pareto前沿 P*

1. P ← P₀, G ← G_init
2. FOR t = 1, ..., T_max:
3.    G_new ← ∅
4.    
5.    // 阶段A：间隙检测与加密
6.    SORT P by f₁
7.    FOR 存档P中每对相邻非支配解 (y_i, y_{i+1}):
8.        d_obj ← ||y_i − y_{i+1}||₂
9.        IF d_obj > d_threshold:
10.           w_mid ← interpolate_weights(y_i, y_{i+1})
11.           G_new ← G_new ∪ {w_mid}
12.   
13.   // 阶段B：HV热点导向微扰
14.   FOR 每个已探索权重 w ∈ G:
15.       P_wo ← P \ {w产生的解}
16.       contribution ← HV(P, r) − HV(P_wo, r)
17.       IF contribution > 0.2 × mean_contributions:
18.           FOR k = 1, 2:
19.               w_perturb ← w + N(0, σ·I)
20.               PROJECT w_perturb onto simplex  // Σwᵢ=1, wᵢ≥0
21.               G_new ← G_new ∪ {w_perturb}
22.   
23.   // 阶段C：去重与边界保护
24.   G_new ← DEDUPLICATE(G_new, tol=0.05)
25.   REMOVE w from G_new if ANY(wᵢ < 0.02)
26.   IF G_new = ∅: BREAK
27.   
28.   // 阶段D：量子求解与存档更新
29.   FOR w ∈ G_new:
30.       H_single ← w₁·f₁^norm + w₂·f₂^norm + w₃·f₃^norm + H_penalty(λ_PenaltyFlex_final)
31.       // f_i^norm 按§4.1归一化层：粗网格用物理先验(f₁/30,f₂/10)，ParetoZoom用动态归一化
32.       solutions ← kaiwu.solve(H_single, num_reads=1000)
33.       FOR sol ∈ TOP-20(solutions):
34.           c ← decode(sol)
35.           IF constraints_satisfied(c, tol=2%):
36.               y ← (f₁(c), f₂(c), f₃(c))
37.               P ← nondominated_update(P, y)
38.   
39.   // 阶段E：HV收敛判定
40.   HV⁽ᵗ⁾ ← HV(P, r)
41.   IF |HV⁽ᵗ⁾ − HV⁽ᵗ⁻¹⁾| / HV⁽ᵗ⁾ < ε_HV: BREAK
42. 
43. RETURN P
```

#### 4.2.4 ParetoZoom关键设计说明

| 组件 | 功能 | 物理意义 |
|------|------|---------|
| **间隙检测** | 发现目标空间"空洞" | 两个解距离太远 = 中间可能有更好的权衡解 |
| **权重插值** | 单纯形上生成中点权重 | 保持w₁+w₂+w₃=1 |
| **HV贡献度** | 识别"高价值权重方向" | 某些权重恰好产出扩展HV的关键解 |
| **高斯微扰** | 在热点附近加密 | 微调探索半径，不改变方向本质 |
| **边界保护** | 删除wᵢ<0.02的极端权重 | 避免单目标退化数值不稳定 |
| **HV参考点** | r = (max f_i + δ_i)，δ_i = 10%目标范围 | 确保参考点严格支配所有解，HV > 0 |

#### 4.2.5 双层自适应架构

| 层次 | 算法 | 控制对象 | 作用域 |
|------|------|---------|--------|
| **外层ParetoZoom** | 4.2.3节 | 权重 (w₁,w₂,w₃) | **Pareto前沿质量**（覆盖度、密度） |
| **内层PenaltyFlex** | 3.2节 | 惩罚系数 λ_carbide, λ_CCr（λ_sum=10~20固定） | **约束满足率**（可行性、精确度） |

协同流程：
1. ParetoZoom提出新权重 `w_new`
2. 查找最近邻 `w_neighbor`（已跑过PenaltyFlex）
3. 以 `w_neighbor` 的PenaltyFlex终值 `λ*` 为 `w_new` 的初值（warm-start）
4. PenaltyFlex跑自适应λ序列，微调至 `λ_new*`
5. `λ_new*` 存入缓存，供后续相邻权重复用

#### 4.2.6 理论预期

| 特性 | 预期 |
|------|------|
| 粗网格调用 | 12组QUBO，每组PenaltyFlex≈10-15轮 → 总计120-180次量子提交 |
| ParetoZoom迭代 | 每轮新增3-8组权重，2-4轮收敛 → 总计20-40次量子提交 |
| 总wall-clock | <30秒（模拟器）/ <2分钟（真机含通信开销） |
| 总quantum提交 | 140-220次 |

## 七、后处理物理过滤器（输出层）

Pareto解输出后，经典层执行物理合理性检查，不消耗量子资源：

```
过滤器：物理合理性检查
────────────────────────
输入：Pareto解 (c₁, c₂, ..., c₆) 及其 (f₁, f₂, f₃)
输出：标记后的推荐列表

IF ΔH_mix < −15 或 ΔH_mix > 10:
    标记 ⚠️ "偏离HEA稳定区间"  // HEA合理区间：-15~10 kJ/mol（Takeuchi-Inoue判据）

IF VEC < 7.0 或 VEC > 7.6:
    标记 ⚠️ "相结构风险"  // 偏离FCC+BCC双相区

IF c_C > 1.0%:
    标记 ⚠️ "碳化物形成风险"  // 间隙C过高可能析出M₂C/M₇C₃

IF ANY(c_i > 35%):
    标记 ⚠️ "偏离HEA定义"  // 传统HEA定义：各元素5~35%

IF |Σc_k − 100%| > 1%:
    标记 ⚠️ "成分和非100%"  // 硬约束应已消除，保留兜底

// δ判据：原子尺寸差（Hume-Rothery固溶准则）
δ = √(Σ_{i∈{Al,Co,Cr,Fe,Ni}} c_i' × (1 − r_i/r̄)²)
r̄ = Σ c_i' · r_i  // 加权平均原子半径
原子半径(Å): Al=1.43, Co=1.25, Cr=1.28, Fe=1.26, Ni=1.24
IF δ > 6.6%:
    标记 ⚠️ "原子尺寸差过大(δ={value}%)，固溶体不稳定风险"

// Ω判据：高熵稳定参数
T_m = Σ_{i∈{Al,Co,Cr,Fe,Ni,C}} c_i · T_{m,i}  // 混合熔点(K)，含C
ΔS_mix = −R · Σ_{i∈{Al,Co,Cr,Fe,Ni}} c_i' · ln(c_i')  // 仅5主元，c_i' = c_i/(1−c_C)
// 说明：C为间隙原子，不贡献位形熵；c_C≪1%时C的熵贡献~0.05R可忽略
Ω = T_m · ΔS_mix / |ΔH_mix|
IF Ω < 1.1:
    标记 ⚠️ "Ω参数过低({value})，混合焓主导，可能形成金属间化合物"

// Δχ判据：电负性差（固溶体形成经典四联判据之一）
Δχ = √(Σ_{i∈{Al,Co,Cr,Fe,Ni}} c_i' × (χ_i − χ̄)²)
χ̄ = Σ c_i' · χ_i  // 加权平均电负性
Pauling电负性: Al=1.61, Co=1.88, Cr=1.66, Fe=1.83, Ni=1.91
IF Δχ > 0.133:
    标记 ⚠️ "电负性差过大(Δχ={value})，元素间电子亲和力差异过大，化合物形成风险"

IF 标记数 = 0:
    标记 ✅ "可直接实验"
```

**作用**：不修改QUBO结构，不消耗量子资源，仅作为输出层清洗。用户看到结果时，高风险解自动降权或折叠。

### A.1 ΔH_{ij}^{AB} 二元混合焓参数表（Miedema模型）

**置换式主元（5×5对称矩阵）**：单位 kJ/mol，来源：Takeuchi-Inoue表（Miedema模型）

|     | **Al** | **Co** | **Cr** | **Fe** | **Ni** |
|:---:|:------:|:------:|:------:|:------:|:------:|
| **Al** | 0 | −19 | −10 | −11 | −22 |
| **Co** | −19 | 0 | −4 | −1 | 0 |
| **Cr** | −10 | −4 | 0 | −1 | −7 |
| **Fe** | −11 | −1 | −1 | 0 | −2 |
| **Ni** | −22 | 0 | −7 | −2 | 0 |

> 等原子比AlCoCrFeNi预测（完整推导）：
> ```
> ΔH_mix = 4 × Σ_{i<j} ΔH_{ij} × c_i × c_j
>        = 4 × (−19−10−11−22−4−1+0−1−7−2) × (0.2)²
>        = 4 × (−77) × 0.04
>        = −12.32 kJ/mol ≈ **−12.2 kJ/mol**（四舍五入）
> ```
> 共10对二元相互作用：Al-Co(−19), Al-Cr(−10), Al-Fe(−11), Al-Ni(−22), Co-Cr(−4), Co-Fe(−1), Co-Ni(0), Cr-Fe(−1), Cr-Ni(−7), Fe-Ni(−2)。

**间隙C-TM交叉项（γ折扣前）**：

|     | Al | Co | Cr | Fe | Ni |
|:---:|:--:|:--:|:--:|:--:|:--:|
| **C** | −39 | −42 | −61 | −50 | −46 |

> 折扣后：`ΔH_{i,C}^{eff} = γ × ΔH_{i,C}^{Miedema}`，γ = 0.2~0.3
