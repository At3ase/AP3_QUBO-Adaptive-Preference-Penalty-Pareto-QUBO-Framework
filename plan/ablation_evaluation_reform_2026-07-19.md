## 1. 问题缘起：实验 0 的 HV 方向性矛盾

实验 0（formal_exp0_reps20，20 reps × 5 配置）按验证方案 §4.0 的设计，应回答「去掉任一创新点，性能是否显著下降」。实际跑批结果方向完全相反：

| 配置 | HV 均值 ± SD | front_size 均值 | 单点 HV 贡献（HV/front_size） |
|---|---|---|---|
| Full | 11686.4 ± 1028.6 | 87.6 | ≈133 |
| Abl-1（去 PrecisionSplit） | **13700.6 ± 1156.1** | 94.5 | ≈145 |
| Abl-2（去 PenaltyFlex） | 10907.4 ± 1120.1 | 51.3 | ≈213 |
| Abl-3（去 ParetoZoom） | 10742.3 ± 1016.4 | 77.0 | ≈140 |
| Abl-4（三创新全去） | **13680.0 ± 1333.8** | 39.8 | ≈344 |

（数据来源：`data/results/formal_exp0_reps20/exp0/records.csv`，统计见诊断报告 §3.1）

**两个消融配置（Abl-1、Abl-4）的 HV 反超 Full。** 配对 Wilcoxon 符号秩检验 + Bonferroni 校正（family=4，ablation.py `compute_pairwise_significance`）显示：

- 4 组 Full vs Abl-i 比较，Bonferroni 校正后 p 全部 < 0.001，最大 p = 2.29e-05；
- rank-biserial 效应量 = ±1.0，即 20/20 个 rep 全部同向，无一反向。

**方法论推论**：统计显著性已经无可辩驳，差异不可能是随机噪声或采样不足。当「统计上铁证如山」与「逻辑上不可能成立」（拆掉组件的系统不可能系统性优于完整系统）同时成立时，问题必然出在**指标定义本身**而非数据。这一判断是本次改革的出发点。

## 2. 根因机制：三层缺陷

### 2.1 第一层（指标层）：HV 只度量体积，不度量物理质量

Hypervolume（`src/ap3_qubo/validation/hypervolume.py`）的定义是「被 Pareto 前沿支配的参考点以上区域的体积」（hypervolume.py:1-9）。它对目标空间的**几何覆盖**敏感，但对解的**物理合法性**完全无感：一个成分为碳化物复合材料（已不属于 HEA/钢范畴）的点，只要伸进了未被覆盖的目标区域，就为 HV 正贡献。

实验 0 的正式 HV 口径（ablation.py `_compute_hv_unified`，:74-90）用每 rep 内 5 配置合并解集统一参考点 `set_unified_reference(margin=0.10)`（hypervolume.py:16-53）——**参考点统一是对的**（否则组间 HV 不可比），但「合并解集」也意味着 Abl 配置伸出的极端点会推高参考点、改变所有人的 HV 刻度，进一步放大几何覆盖差异的权重。

### 2.2 第二层（编码层）：unified_48 的 C 区间结构性保证不可行

`QUBOBuilder._ENCODING_CONFIGS`（`src/ap3_qubo/qubo/builder.py:140-159`，改革前状态）：

- `precision_split_38`（Full/Abl-2/Abl-3 用）：C 为 3 bit，base 0.0，step 0.25 → **C ∈ [0, 1.75] at%**；
- `unified_48`（Abl-1/Abl-4 用，见 ablation.py:211-215、229-234）：C 为 8 bit，base **5.0**，step 30/255 → **C ∈ [5, 35] at%**。

物理过滤器的碳化物高风险阈值为 **C ≥ 1.0 at%**（`src/ap3_qubo/validation/physical_params.py:387-388`），C-Cr 耦合阈值 0.3（:389）。因此：

> **Abl-1/Abl-4 的每一个可能解 C ≥ 5 at%，必然触发碳化物高风险与 C-Cr 耦合超限。这不是采样偏差，是编码区间的结构性保证。**

虚高的具体物理通道：高 C 经 Vegard 密度定律（石墨 ~2.26 g/cm³）系统性拉低 f2（密度）极值，使前沿向「极低密度」方向伸长、扩张目标空间覆盖。佐证：Abl-4 仅用 39.8 个前沿点就拿到 13680 的 HV，单点 HV 贡献 ≈344，是 Full（≈133）的 2.6 倍——它的点必然伸到了 Full 根本不可能到达的目标区域，而那个区域是间隙碳 5–35 at% 的化学荒谬区。

### 2.3 第三层（报告层）：AR 绝对值公式掩盖方向

改革前 `AblationRunner.compute_contributions`（ablation.py:554）的实现为：

```
AR_i = |HV_Abl-i − HV_Full| / HV_Full × 100%
Synergy = Σ|AR_i| − |HV_Abl-4 − HV_Full| / HV_Full × 100%   （:562）
```

绝对值把「去掉组件反而更好」（HV_Abl > HV_Full，本应是**负贡献**）与「去掉组件性能下降」（正贡献）映射为同一个正数。于是 Abl-1 的编码缺陷伪覆盖被报告为 **AR_PrecisionSplit = 17.24%——一个符号错误的「正贡献」**，直接支撑「三组件各有正向独立贡献」的错误结论。

Synergy 同样被污染：分子是 Σ|AR_i|，分母端的 |HV_Abl-4 − HV_Full| 也是绝对值，符号信息双重丢失。

## 3. 核心方法论原则：评价口径必须统一且物理知情

本次改革的论证核心是一条原则：

> **搜索空间可以不同（这正是消融变量的本质），但评价口径必须统一且物理知情（prior-aware）。**

- 消融实验的逻辑是「改变一个组件、保持其余不变」。Abl-1 去掉 PrecisionSplit 后搜索空间确实变了（38→48 变量），这合法；
- 但**评价**若只看几何覆盖（裸 HV），等于奖励「搜索空间里包含更多物理荒谬区」的配置。物理先验（碳化物阈值、Ω 稳定性、成分和约束）在 Full 管线中通过编码区间（C∈[0,1.75]）进入了**搜索**，却在评价时被忽略——结果是先验约束反而被 HV 惩罚：Full 因为「不去碰荒谬区」而覆盖更小、HV 更低。
- 原则的对偶表述：**物理先验不进搜索则必须进评价，二者必居其一，否则先验成为惩罚自己的枷锁。**

由此导出改革的两条互补措施（见 §6）：

1. **对齐搜索空间**：unified 编码元素范围与 PrecisionSplit 对齐（C [0,1.75]、主元 [5,36.75]），把消融变量纯净化为「编码结构差异」而非「化学空间差异」；
2. **评价物理知情**：feasible-HV + 真实分层可行指标，使「不可行的覆盖」不再计入贡献。

## 4. 循环论证的防范：先验合法性必须先独立验证

用「物理先验过滤后的 HV」来评价消融，存在一个显见的循环论证风险：如果先验本身是错的，feasible-HV 只是把一个错误换成了另一个错误，且结论变成「先验说它好所以它好」。

防范方式是**论证链的顺序**：

```
实验 5（独立验证先验） → 先验合法 → feasible-HV 口径合法 → 消融结论成立
```

- 实验 5（Pycalphad 回测 + 文献回测 + 负对照）的验收标准：CAR ≥ 80%（Pycalphad 一致率）、NDR = 100%（负对照拒绝率）、Cohen's κ > 0.6（文献一致性）。这些判据与消融实验**完全独立**——它们检验的是 `physical_filters.py` 规则本身的物理正确性，不涉及任何 QUBO 求解结果。
- 因此 feasible-HV 口径的合法性不依赖消融结论，循环被切断。
- **排期推论**：实验 5 在验证方案保底顺序中排第 5（表面 P2），但它是消融结论的方法论前提，**其实际优先级高于表面的 P2**。在消融重跑结果进入论文之前，实验 5 必须先有结论；否则论文中所有 feasible 口径数字都应标注「先验待独立验证」。

## 5. 诊断新发现与开放问题

诊断报告在排查过程中暴露了三个超出原问题范围的事实，必须如实记录，不得静默处理。

### 5.1 Full 代表性前沿 strict 可行率 0%：VEC 窗口与目标函数结构性冲突

对 Full 唯一可用的代表性前沿（`exp0/representative_compositions.csv` + `representative_front.npz`，99 点，`run_experiments.py:281-289` 的 `_representative_run` 产物）施加 `PhysicalFilter` strict `all_pass`（physical_filters.py:220-229，阈值见 physical_params.py:362-389）：

- **99/99 点全部未通过，可行率 0.0%**；
- 根因：99 点 VEC 分布 min 5.73 / 中位 6.48 / **max 6.90 < 7.0**——VEC ∈ [7.0, 7.6] 窗口在整个前沿上不可达。机制是 f2（密度）/f3（成本）最小化压力把前沿推向 Al 富集区（Al 的 VEC=3），主元归一化 VEC 被系统性拉低。

**这是物理设计层面的开放问题**：VEC 约束与现有 3 目标存在结构性 Pareto 冲突，不是个别解的问题，也不能靠过滤口径技巧掩盖。选项（诊断报告 §5-3）：放宽 VEC 窗口到可达域（需物理依据）、或将 VEC 从过滤条件改为第 4 目标/惩罚项。**处理方式：在论文中作为设计讨论如实呈现，或由项目正式决策窗口/目标设计，不得静默修改。** 直接后果：strict `all_pass` 不可用作 feasible 硬门槛（否则全员归零、指标退化），故改革采用「仅 FAIL 级」为硬口径（见 §6-3）。

### 5.2 档案容差与过滤容差不一致

ParetoZoom 入档放行 |Σc − 100| ≤ 2.0%（`exploration/pareto_zoom.py:101` 附近），而过滤器 SUM_TOLERANCE = 1.0%（physical_params.py:384 附近）。Full 代表性前沿 52/99 点的成分和偏差落在 (1%, 2%] 这个「入档合法但过滤非法」的夹层，口径永远说不清。已在改革中统一为 1%（见 §6-6）。

### 5.3 Abl-1 多出的覆盖是伪覆盖：排除「先验收太紧漏掉好解」

对「Abl-1 反超是否因为 Full 的先验约束太紧、漏掉了真正的好解」这一备择假说，结构性回答是否定的：Abl-1 的可行候选必须 C ≥ 5 at%（编码区间保证），在任何保留碳化物检查的口径下都不可行；其多出的覆盖位于**碳化物复合材料化学区**，是编码缺陷放进来的伪覆盖，不是被先验误杀的好解。（边界声明：若未来重跑在 C∈[5,35] 区发现「放宽碳化物约束后可行且支配 Full」的点，应归类为编码区间设计错误，而非科学发现——见诊断报告 §4-Q3。）

## 6. 改革方案（已实施的代码修正）

以下修正已由代码同事完成并落地，每项注明理由。修改未触碰 `src/ap3_qubo/visualization/` 与 `data/`，不影响正在运行的 formal_exp2_reps20（PID 22092，目标文件已在其进程内存中）。

### 6.1 unified 编码元素范围与 Full 对齐（消融变量纯净化）

`unified_48` / `unified_38` 元素范围与 PrecisionSplit 对齐：C [0, 1.75] at%、主元 [5, 36.75] at%。

**理由**：消融实验要量化的是「编码结构（统一 vs 分层精度）」的边际贡献，而不是「化学空间（含碳化物复合材料区 vs 不含）」的差异。对齐后 Abl-1/Abl-4 不再被结构性保证不可行，对比恢复意义。对应 §3 原则的第一条措施。

### 6.2 front 逐 rep 落盘

ablation.py 每 rep 每配置落盘 `fronts/{config}_rep{NN}.npz`，含 objectives、fractions、hard_feasible 掩码。

**理由**：诊断报告 §1 的核心数据缺口——`AblationResult` 只回传 hv/front_size 标量（ablation.py:66-71），前沿矩阵在 `_compute_hv_unified` 内瞬时使用后丢弃，导致任何事后可行的 feasible 口径分析都无法进行。落盘使评价口径可迭代（改口径不必重跑优化），也是 §6.3/6.4 指标的数据前提。

### 6.3 真实分层可行指标

- `feasible_rate` 改为**硬口径**：仅 FAIL 级（Ω 不稳定 / 碳化物高风险 / 成分和超差）判不可行；
- `physical_pass_rate` 为 strict `all_pass`，仅作记录不作门槛；
- 软指标（VEC / δ / Ω / ΔH_mix）单列报告。

**理由**：(a) 旧 records.csv 的 feasible_rate/physical_pass_rate 是 `AblationResult` dataclass 默认值 1.0000 的占位符（ablation.py:69-70），全代码库无赋值点，不能用作证据——必须真算；(b) strict `all_pass` 因 VEC 窗口不可达会全员归零（§5.1），不可用作硬门槛；(c) 诊断报告 §2.3 的口径谱系显示「仅 FAIL 级」是保留碳化物检查的前提下 Full 仍保有 29.3% 可行率的最低失真口径（HV 虚高幅度 16.7%，远低于放宽 VEC/HEA 的 24–50%）；(d) 软指标单列保证信息不丢失——VEC 冲突作为开放问题在报告层可见，而非被硬门槛静默吞掉。

### 6.4 feasible-HV

hypervolume.py 新增 `compute_feasible_hv`：沿用统一参考点口径（`set_unified_reference`），仅对可行点集计算 HV；空可行集返回 **NaN** 而非 0。

**理由**：(a) 对应 §3 原则的第二条措施，使「不可行的覆盖」不再计入贡献；(b) 空可行集返回 NaN 是「不伪造」原则——0 是一个合法的（很差的）HV 值，会把「无可行解」伪装成「前沿质量差」；NaN 则正确表达「该口径下指标无定义」。此约定与全失败配置 AR 记 NaN（ablation.py:537-539）的既有口径一致。

### 6.5 带符号 AR/Synergy 与 Feasible_AR

- AR 改为带符号：`AR_i = (HV_Full − HV_Abl-i) / HV_Full × 100%`（正 = 去掉该组件性能下降 = 组件有正贡献）；
- Synergy 同步带符号化；
- 旧绝对值口径保留为 `*_abs_legacy` 并标注废弃（deprecated）；
- 新增 `Feasible_AR` / `Feasible_Synergy`：基于 feasible-HV 的带符号版本，作为主报告口径。

**理由**：修复 §2.3 的方向掩盖。「去掉反而更好」必须报告为负贡献，符号是消融解释的本体。保留 `*_abs_legacy` 是为了与旧结果做历史对照（见 §7），而不是两套口径并存竞争。Feasible_AR 是 §3 原则在贡献率指标上的最终落地：搜索空间不同 + 评价统一且物理知情。

### 6.6 容差统一

档案入档容差与过滤容差统一为 1%（消除 §5.2 的 (1%, 2%] 夹层）。

**理由**：1% 是过滤器既有阈值（physical_params.py:384 附近），向严格侧统一使「入档即可过滤评价」自洽；代价是 (1%, 2%] 夹层点不再入档，前沿点数的轻微损失换取口径的确定性。

### 6.7 配套口径说明：实验 4 参数

实验 4（γ 敏感性）实际设计为 **5 个 γ 值、基准 0.3**（git HEAD 中的 6 值/0.25 是旧版本）。本文档及后续报告一律按 5 值/0.3 引用，避免与重跑产物不一致。

## 7. 重跑计划

- **触发条件**：实验 2 reps20（PID 22092）结束后，由用户调度启动。诊断期间实验 2 处于 rep 18/20；串行执行避免 CPU 争抢拖慢两边。

- **旧结果处置**：formal_exp0_reps20 的 absolute-AR 口径结果标记为 **deprecated**，仅作历史对照（例如回答「改革改变了什么」），不得再作为消融结论的证据引用。

## 8. 对论文/答辩表述的影响

**在重跑完成前，消融章节不能声称「三组件各有正向独立贡献」。**

- 当前证据能支撑的最强表述仅为：**「组件对搜索结果有统计显著影响」**（4 组 Wilcoxon 校正后 p < 0.001，rank-biserial ±1.0，20/20 同向——影响的**存在性**无可辩驳，但影响的**方向与大小**在旧口径下不可解释）。
- AR_PrecisionSplit = 17.24%（绝对值口径）是符号错误的产物（§2.3），禁止引用；旧口径一切 AR/Synergy 数字同此。
- 答辩若被问「每个创新点贡献多少」，当前诚实回答是：贡献的方向性结论待重跑（约 4.1 小时，已排期），改革本身（发现指标缺陷 → 诊断根因 → 独立验证先验 → 口径修正）可作为方法论严谨性的正面证据呈现。
- 图 7（消融堆叠柱状图，验证方案 §6）在重跑产物出来前不更新；旧图随 absolute-AR 一并 deprecated。
- VEC 窗口与 f2/f3 的结构性冲突（§5.1）应作为「设计讨论/局限性」写入论文，而非等到评委指出。
