## 一、P0-1：研究边界声明（§1.4 新增）

### 1.1 方案定位：计算成分筛选框架

**材料设计是一个从元素选择 → 成分优化 → 相图预测 → 组织建模 → 工艺设计 → 性能验证的长链条。** 本方案聚焦于**"成分-热力学-成本"的第一层筛选**，在严格物理约束下高效搜索成分空间，为后续组织设计、工艺优化和实验验证提供**高质量的候选成分库**。

```
材料设计四级金字塔
┌─────────────────────────────────────┐
│  第四层：力学性能验证                │
│  硬度、屈服强度、延伸率、蠕变、耐磨  │
│  → 实验测试（电弧熔炼、XRD/SEM/TEM）│
├─────────────────────────────────────┤
│  第三层：工艺-组织耦合                │
│  凝固速率、热处理制度、增材制造参数  │
│  → 工艺模拟与实验迭代               │
├─────────────────────────────────────┤
│  第二层：组织建模                    │
│  Hall-Petch、固溶强化、析出强化模型  │
│  → 微观力学模拟                     │
├─────────────────────────────────────┤
│  ★ 第一层：成分-热力学筛选（本方案） │
│  ΔH_mix（热力学）+ 密度 + 成本       │
│  → 量子优化 + CALPHAD 验证           │
└─────────────────────────────────────┘
```

### 1.2 核心假设声明

| 假设 | 含义 | 后续扩展方向 |
|------|------|-------------|
| **单相固溶体假设** | 优化面向单相 FCC/BCC 固溶体 HEA | 引入析出相体积分数，扩展至多相设计（EHEA、B2+σ 析出强化） |
| **平衡态假设** | 假设合金经过充分均匀化退火，达到热力学平衡 | 耦合凝固速率、热处理制度，引入非平衡组织模型 |
| **固溶体假设** | P1/P2 碳化物约束在固溶态工作，不考虑时效析出动力学 | 引入 TTT/CCT 曲线或析出动力学模型 |
| **已知体系假设** | 聚焦 AlCoCrFeNi-C 基准体系，不扩展元素库 | 元素筛选（50 选 5-6）通过增加选择变量扩展 |

### 1.3 研究范围声明

**本方案明确不覆盖的内容**：
1. **元素种类选择**：固定 AlCoCrFeNi-C 六元体系，不探索其他元素组合
2. **微观组织建模**：无晶粒尺寸、析出相体积分数、位错密度
3. **工艺参数耦合**：无凝固速率、热处理制度、增材制造参数
4. **直接力学性能优化**：不优化硬度、屈服强度、延伸率、蠕变等
5. **实验验证**：2 个月周期内纯计算，无熔炼/测试资源

**上述内容的定位**：属于材料设计链条的后续环节，将在本方案输出的候选成分库基础上展开。

## 二、P0-2：后处理物理验证层升级（§6.5 扩展）

### 2.1 两层验证架构

本方案采用**"量子优化 + CALPHAD 验证"的两层架构**：

| 层次 | 工具 | 功能 | 精度 | 速度 |
|------|------|------|------|------|
| **第一层：量子优化** | Miedema 代理模型 | 快速筛选候选成分 | 经验公式（±5-10 kJ/mol） | 毫秒级/次 |
| **第二层：CALPHAD 验证** | Pycalphad（SGTE/TC 数据库） | 精确相平衡计算 | 热力学数据库驱动 | 分钟级/成分 |

> 这种"快速代理 + 精确验证"是 Materials Project、AFLOW 等高通量平台的通用范式。

### 2.2 Ω 判据：热力学稳定性分级验证

**原方案**：仅标记 ⚠️ "Ω 参数过低"

**升级后**：三级输出系统

```
Ω = T_m · ΔS_mix / |ΔH_mix|

分级标准：
- Ω ≥ 1.1：✅ 热力学稳定（固溶体形成能高于金属间化合物驱动力）
- 0.8 ≤ Ω < 1.1：⚠️ 亚稳态（低温下稳定，高温可能分解）
- Ω < 0.8：❌ 热力学不稳定（ΔH_mix 主导，金属间化合物形成倾向显著）
```

**物理意义**：
- Ω 判据解决 f₁ 仅优化 ΔH_mix（忽略熵项）的简化假设问题
- 高温（>800°C）场景下，T·ΔS_mix ≈ 17.4 kJ/mol 与 ΔH_mix 同量级，Ω 判据作为**兜底验证**
- 所有 Ω<1.1 的解自动标记风险等级，不进入"可直接实验"推荐列表

### 2.3 δ-Ω 联合判据：弹性畸变风险综合评估

**原方案**：δ>6.6% 单独标记

**升级后**：δ-Ω 联合判据

| 条件 | 标记 | 说明 |
|------|------|------|
| δ ≤ 6.6% 且 Ω ≥ 1.1 | ✅ 无风险 | 固溶体稳定区 |
| δ > 6.6% 且 Ω ≥ 1.1 | ⚠️ 高畸变风险 | 原子尺寸差过大，但热力学仍可形成固溶体。建议转入多相设计或降低 δ 元素含量 |
| δ ≤ 6.6% 且 Ω < 1.1 | ⚠️ 热力学不稳定 | 虽畸变小，但混合焓过负，可能形成金属间化合物 |
| δ > 6.6% 且 Ω < 1.1 | ❌ 极高风险 | 高畸变+低稳定性，固溶体不可行。建议排除或大幅调整成分 |

**物理说明**：Miedema 模型在本体系中未显式包含弹性畸变焓 ΔH_dis。我们以 Hume-Rothery 原子尺寸差 δ 作为 ΔH_dis 的零阶代理，因为弹性畸变能与原子尺寸差存在二次关系（ΔH_dis ∝ δ²）。δ>6.6% 的解标记为"高畸变风险"，建议排除或转入多相设计流程。

### 2.4 温度敏感性标记（新增）

针对碳化物析出动力学问题，增加温度相关标记：

| 标记条件 | 标记内容 | 物理依据 |
|---------|---------|---------|
| c_C > 0.5% | ⚠️ 建议在 1100°C 以上固溶后快冷 | 防止 600-900°C 时效窗口碳化物析出 |
| c_C > 0.8% | ⚠️ 固溶态风险高，需实验验证时效稳定性 | 超过保守固溶区上限 |
| c_C × c_Cr / 64.3125 > 0.3 | ⚠️ 600-900°C 时效窗口存在碳化物析出风险 | C-Cr 协同效应显著 |
| c_C > 0.5% 且 δ > 6.6% | ❌ 高 C + 高畸变，碳化物析出倾向极高 | 双重风险叠加 |

> **声明**：P1/P2 约束在当前版本中作为固溶区边界条件工作，尚未包含温度-时间路径的析出动力学。后续工作将通过 TTT 曲线或析出相体积分数模型来扩展。

## 三、P0-3：Pycalphad 相验证层升级（实验 5）

### 3.1 从"后处理检查"到"相稳定性验证层"

**升级前**：Pycalphad 定位为"物理合理性检查"，可选执行

**升级后**：Pycalphad 升级为**必做验证层**，对 Top20 候选成分执行温度扫描

### 3.2 验证方案

**验证对象**：量子优化产出的 Top20 候选成分（按 HV 贡献度选择）

**验证内容**：

| 温度点 | 验证目标 | 排除条件 |
|--------|---------|---------|
| **500°C** | 室温/低温服役稳定性 | 出现 σ 相、Laves 相、碳化物（M₂₃C₆/M₇C₃） |
| **800°C** | 中温服役稳定性 | 出现任何有害相 >5% 体积分数 |
| **1100°C** | 高温固溶/铸造条件 | 单相固溶体不可行 |

**新增指标**：

| 指标 | 符号 | 定义 | 目标值 |
|------|------|------|--------|
| 相稳定性通过率 | **PSR** | Pycalphad 验证通过数 / 验证总数 × 100% | ≥ 70% |
| 计算一致率 | CAR | N_agreement(Pycalphad) / N_total × 100% | ≥ 80% |
| 负对照检测率 | NDR | N_detected(负对照) / N_negative × 100% | 100% |
| 文献回测一致率 | LAR | N_agreement(文献) / N_literature × 100% | ≥ 75% |

> PSR ≥ 70% 的设定考虑了六元含 C 体系的数据库覆盖度限制。对数据库覆盖不足的成分，标记为"待验证"而非自动排除。

### 3.3 验证流程

```
验证流程：
────────────────────────
输入：Top20 候选成分

Step 1: 数据库覆盖度检查
  IF 数据库缺失某成分数据 → 标记"数据库覆盖不足，建议实验验证"
  ELSE → 进入 Step 2

Step 2: 温度扫描（500°C / 800°C / 1100°C）
  FOR 每个温度 T:
    计算平衡相组成
    IF 有害相（σ/Laves/碳化物）体积分数 > 5% → 标记"T°C 不稳定"
  ENDFOR

Step 3: 与 Miedema 预测对比
  IF Pycalphad 与 Miedema 一致 → 标记"计算一致"
  IF Pycalphad 与 Miedema 矛盾 → 标记"需人工复核"

Step 4: 负对照验证
  对 1-2 个极端成分（如 C>3%）执行相同流程
  IF 负对照未被检出 → 标记"验证方法不可靠"
  ELSE → 验证通过

输出：标记后的候选成分列表
────────────────────────
```

## 四、P0-4：创新声明调整（§11 修改）

### 4.1 原创新声明（300 字）

> 本方案提出 AP³-QUBO 框架，针对 AlCoCrFeNi-C 高熵合金成分优化的核心挑战——在严格物理约束下高效搜索巨大成分空间——实现三项技术创新：
> (1) PrecisionSplit 分层编码将 QUBO 变量数从 48 压缩至 38，降低 20.8% 求解规模，在同等量子资源下可扩展至 7 元体系；
> (2) PenaltyFlex 自适应惩罚使可行解率相比 Grid-search 最优固定 λ 提升 10% 以上（p < 0.01），收敛速度加快 30%；
> (3) ParetoZoom 动态探索使 Pareto 前沿 Hypervolume 提高 10% 以上，非支配解数量增加 30%。
> 消融实验证明三个创新点各有独立正贡献（每项贡献率 > 3%），NSGA-II 对比实验证明量子方法在同等求解预算下不劣于经典多目标进化算法。Pycalphad 物理验证一致率 ≥ 80%。

### 4.2 修改后创新声明（350 字）

> 本方案提出 **AP³-QUBO 计算成分筛选框架**，针对 AlCoCrFeNi-C 高熵合金在航天高温结构件应用中的**前置筛选需求**——在工程约束（密度/成本）和物理约束（热力学稳定性）下高效搜索成分空间——实现三项技术创新：
>
> **(1) PrecisionSplit 分层编码**：将 QUBO 变量数从 48 压缩至 38，降低 20.8% 求解规模，编码压缩率 20.8% 为**设计属性**，意味着在同等量子资源下可直接扩展至 7 元体系而不过载；
>
> **(2) PenaltyFlex 自适应惩罚**：使可行解率相比 Grid-search 最优固定 λ 提升 10% 以上（p < 0.01），收敛速度加快 30%。该自适应机制是**经典-量子通用**的算法贡献，可独立于量子硬件复用；
>
> **(3) ParetoZoom 动态探索**：使 Pareto 前沿 Hypervolume 提高 10% 以上，非支配解数量增加 30%。基于 HV 热点的权重动态加密机制同样适用于经典多目标优化。
>
> 消融实验证明三个创新点各有独立正贡献（每项贡献率 > 3%）。NSGA-II 对比实验证明在**同等求解预算下**量子方法不劣于经典多目标进化算法——**38 变量是概念验证规模**，算法创新的可扩展性在 7-8 元体系（50+ 变量）中将更显著。Pycalphad 相验证层采用**温度扫描（500/800/1100°C）**确保候选成分在目标服役温度区间的相稳定性，相稳定性通过率（PSR）≥ 70%。

| 修改 | 原表述 | 修改后 | 目的 |

## 五、P1-1：目标函数重新包装（§4.1 扩展）

### 5.1 三目标分层架构

现有三目标在材料设计中的真实定位：

```
目标函数分层架构：
┌─────────────────────────────────────┐
│  第一层：工程约束（必须满足）        │
│  f₂=密度 → 航天结构件减重刚性约束     │
│  f₃=成本 → 工程工业化可行性约束       │
├─────────────────────────────────────┤
│  第二层：热力学前提（必须满足）        │
│  f₁=ΔH_mix → 确保固溶体形成           │
│  Ω判据 → 确保高温稳定性               │
├─────────────────────────────────────┤
│  第三层：力学性能（后续扩展）          │
│  硬度、屈服强度、延伸率、蠕变（未来）  │
│  → 实验测试或代理模型（ML势函数）     │
└─────────────────────────────────────┘
```

### 5.2 每个目标与力学性能的关系

| 目标 | 与力学性能的关系 | 文献支撑 |
|------|-----------------|---------|
| **f₁=ΔH_mix** | 热力学稳定性是力学性能的前提。不稳定的合金会分解为脆性相（如 σ 相、Laves 相），导致力学性能不可预测。Guo et al. (2015) 证明 AlCoCrFeNi 系合金的高温蠕变抗性与热力学稳定性正相关。 | Gorr et al., 2015 |
| **VEC（后处理）** | VEC 直接决定相结构（FCC/BCC）。FCC 韧性好、BCC 强度高。通过控制 VEC 在 7.0-7.6，可确保双相组织兼具强度和韧性。 | Guo et al., 2011; Yang et al., 2020 |
| **f₂=密度** | 航天结构件的刚性约束。密度超标的合金无论力学性能多好都无法上天。本方案将密度作为独立优化目标，而非硬约束，允许 Pareto 前沿自然涌现密度梯度。 | — |
| **f₃=成本** | 工程可行性约束。Co（~$50/kg）和 Ni（~$20/kg）的高价格限制工业化规模。成本优化确保候选成分在经济上可接受。 | — |

### 5.3 答辩核心话术

> "三目标中，密度和成本是航天结构件与工业化的**刚性约束**——密度超标的合金无法上天，成本过高的合金无法量产。热力学稳定性是力学性能的**前提条件**——不稳定的合金会分解为脆性相，后续力学性能优化无从谈起。本方案解决的是**前置筛选**：在满足工程约束和热力学前提的条件下，输出候选成分库。力学性能优化（硬度、屈服强度、蠕变）将在候选成分库的基础上，通过后续实验和工艺优化完成。"

## 七、13 维度答辩 Q&A 预判

### 维度 1：元素选择
**评委**："为什么只优化 6 个固定元素，不从更大的元素库中选择？"
**回答**："成分优化与体系设计是材料设计的两个层次。AlCoCrFeNi-C 是已被广泛研究的高温 HEA 基准体系，在已知体系内找到最优配比本身就是一个具有组合爆炸难度的优化问题。元素筛选将在后续工作中通过引入额外的选择变量（如 50 选 5-6）来扩展。当前工作的价值在于验证编码-惩罚-前沿三层架构在可控规模下的有效性。"

### 维度 3：热力学稳定性
**评委**："你们只用 ΔH_mix，忽略了熵项，高温下会不会误判？"
**回答**："我们在优化阶段使用 ΔH_mix 作为快速代理，这是 Miedema 模型的标准做法。在验证阶段，后处理层引入 Ω = T_m·ΔS_mix/|ΔH_mix| 判据作为热力学稳定性的第二层验证。所有 Ω<1.1 的解自动标记为亚稳态，不进入推荐列表。对于 >800°C 的高温应用，我们增加了 Pycalphad 相图验证，确保候选成分在目标温度区间保持相稳定。"

### 维度 5：相图验证
**评委**："你们没有 CALPHAD 硬约束，怎么保证最优解在 800°C 不分解？"
**回答**："本方案采用'量子优化 + CALPHAD 验证'的两层架构。量子优化利用 Miedema 代理快速筛选，单次毫秒级；对 Top20 候选成分，使用 Pycalphad 在 500°C、800°C、1100°C 执行相平衡计算，验证是否存在 σ 相、Laves 相或碳化物析出。这种'快速筛选 + 精确验证'是 Materials Project 等高通量平台的标准范式。相稳定性通过率（PSR）是我们的物理验证指标之一。"

### 维度 7：微观组织
**评委**："成分优化不涉及组织，但组织才是力学性能的载体。你们怎么回答？"
**回答**："完全同意。成分→相→组织→性能是材料设计的四级金字塔，本方案解决的是金字塔底层——成分-热力学筛选。我们明确将方案定位为'计算成分筛选框架'，而非'完整材料设计平台'。输出的候选成分库为后续的组织设计（Hall-Petch、析出强化）和工艺优化（凝固速率、热处理制度）提供高质量的起点。这类似于药物发现中的虚拟筛选——先缩小候选范围，再深入优化。"

### 维度 9：性能目标
**评委**："密度和成本是选型指标，不是设计指标。你们应该优化力学性能。"
**回答**："密度和成本在航天结构件场景下是刚性约束——密度超标的合金无法上天，成本过高的合金无法量产。热力学稳定性是力学性能的前提条件——不稳定的合金会分解为脆性相，后续力学性能优化无从谈起。本方案解决的是'前置筛选'：在满足工程约束和热力学前提的条件下，输出候选成分库。力学性能优化（硬度、屈服强度、蠕变）将在候选库的基础上通过实验和工艺优化完成。"

### 维度 11：实验验证
**评委**："纯计算没有实验验证，怎么证明结果可信？"
**回答**："本方案受限于 2 个月周期和资源，采用'计算先行、实验跟进'策略。计算结果通过三层验证确保可靠性：①Miedema 代理模型的文献基准验证；②Pycalphad 相图计算验证（温度扫描 500/800/1100°C）；③文献回测验证。此外，负对照验证确保物理过滤器的检测能力。团队已与合作实验室建立联系，实验验证（电弧熔炼、XRD/SEM、力学测试）已纳入下一步工作计划。"

### 维度 13：量子必要性
**评委**："38 个变量经典算法完全可以处理，为什么要用量子？"
**回答**："38 变量是概念验证规模，目的是在可控条件下验证三层创新架构（PrecisionSplit+PenaltyFlex+ParetoZoom）的协同有效性。PenaltyFlex 和 ParetoZoom 的自适应机制是经典-量子通用的算法贡献，可直接复用于经典优化。PrecisionSplit 的编码压缩优势（20.8%）在扩展至 7-8 元体系（50+ 变量）时更加显著。本方案的核心价值是算法创新，量子硬件是其实现载体之一。"
