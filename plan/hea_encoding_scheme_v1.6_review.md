## 一、新发现的问题（v1.6 引入）

### 🔴 新增缺陷 A：惩罚项归一化的数学错误

**问题定位**：§3.1 量级归一化，第 123-131 行

文档声称：

> ```
> S_var' = S_var / 75  // 归一化，使 S_var' ∈ [−1/3, ~8.56]
> ```

**第一性原理验证**：

S_var 的定义为 `S_var = S − S_const = Σ(step_k × Σ 2^j x_{k,j})`，其中各项均为非负：
- S_const = 5 × 5.0% + 0.0% = 25%
- S_var_min = 0（所有 k_i = 0, k_C = 0）
- S_var_max = 0.25% × (5 × 127 + 7) = 0.25% × 642 = **160.5%**

因此：
```
S_var' = S_var / 75 ∈ [0, 160.5/75] = [0, 2.14]
```

**文档的错误**：
1. **下界错误**：`−1/3`（约 −0.33）是错的，正确为 `0`。S_var 不可能为负——它是非负变量系数的和。
2. **上界错误**：`~8.56` 是错的，正确为 `~2.14`。`8.56 = 642/75`，而 642 是 K 的最大值（编码整数和），不是 S_var（S_var = 0.25% × 642 = 1.605，S_var/75 = 1.605/75… 不对，等等）。

让我重新检验文档的计算逻辑。文档将 S_var 定义为百分比差值的百分比数值：`S_var = S − S_const`，其中 S 为总成分百分比。S_var 是直接以百分比为单位的数值。

但文档第 123 行说 `S_var' ∈ [−1/3, ~8.56]`。`8.56 × 75 = 642`，而 642 恰好是 K_max = 5×127+7。但 K 是编码整数值，不是 S_var！

K × 0.25% = S_var，所以 S_var_max = 642 × 0.25 = 160.5（百分比单位）。文档似乎混淆了 **K 的数值** 和 **S_var 的数值**，用 K_max 代替了 S_var_max。

> 换句话说：文档作者可能在心里计算的是 `K/75 ∈ [0, 8.56]`（编码整数范围），而不是 `S_var/75 ∈ [0, 2.14]`（成分百分比范围）。这是量纲混淆。

**后果**：归一化因子 75 仍然可用（它是成分和约束的 required offset），但范围的错误声明影响了系数量级的预估。实际 S_var' 范围 [0, 2.14] 意味着惩罚项 `(S_var' − 1)²` 在 [0, 1.3] 内变化，而不是文档预期的 [0, ~57]。这对 λ_sum 的调参有实际影响。

**建议修正**：

```
修正后的正确表述：
S_var ∈ [0, 160.5]   （百分比单位）
S_var' = S_var / 75 ∈ [0, 2.14]
(S_var' − 1)² ∈ [0, 1.30]   （最坏情况：极小值为0时可达1，最大值为2.14时可达1.30）

数值验证：
- K = 300（等原子比）→ S_var = 75 → S_var' = 1 → 惩罚 = 0 ✅
- K = 0（所有元素最低）→ S_var = 0 → S_var' = 0 → 惩罚 = 1
- K = 642（所有元素最高）→ S_var = 160.5 → S_var' = 2.14 → 惩罚 = 1.30
```

### 🟡 新增缺陷 B：H_carbide = max(0, c_C − 0.8%)² 在 QUBO 中不可精确表示

**问题定位**：§3.2.2 P1 约束

**第一性原理分析**：

`max(0, c_C − 0.8)²` 是一个分段二次函数。对于 3 个二进制变量编码的 C（8 个离散状态），该函数在 8 个离散点上的取值：

| k_C | c_C | max(0, c_C − 0.8)² |
|-----|------|---------------------|
| 0 | 0.00% | 0 |
| 1 | 0.25% | 0 |
| 2 | 0.50% | 0 |
| 3 | 0.75% | 0 |
| 4 | 1.00% | 0.04 |
| 5 | 1.25% | 0.2025 |
| 6 | 1.50% | 0.49 |
| 7 | 1.75% | 0.9025 |

**QUBO 表示性验证**：

一个 QUBO 形式 `H(x) = c + Σ_i a_i x_i + Σ_{i<j} b_{ij} x_i x_j` 在 3 个二元变量上有 **7 个自由度**（1 常数 + 3 线性 + 3 二次），但需要匹配 **8 个离散值**。由于 QUBO 禁止三体项 `x_35·x_36·x_37`，自由度少 1。

试求解：设 C 变量为 x₀, x₁, x₂，QUBO 形式为 `c + a₀x₀ + a₁x₁ + a₂x₂ + b₀₁x₀x₁ + b₀₂x₀x₂ + b₁₂x₁x₂`，匹配 8 个值：

```
u=0: c = 0                           → c = 0
u=1: c + a₀ = 0                      → a₀ = 0
u=2: c + a₁ = 0                      → a₁ = 0
u=3: c + a₀ + a₁ + b₀₁ = 0           → b₀₁ = 0
u=4: c + a₂ = 0.04                   → a₂ = 0.04
u=5: c + a₀ + a₂ + b₀₂ = 0.2025     → b₀₂ = 0.1625
u=6: c + a₁ + a₂ + b₁₂ = 0.49       → b₁₂ = 0.45
u=7: c + a₀ + a₁ + a₂ + b₀₁ + b₀₂ + b₁₂
     = 0 + 0 + 0 + 0.04 + 0 + 0.1625 + 0.45
     = 0.6525 ≠ 0.9025               ❌ 不匹配！误差 = 0.25 (27.7%)
```

**结论**：`max(0, c_C − 0.8)²` 在 3 比特 QUBO 编码中 **数学上不可精确表示**。这是分段函数与 QUBO 二次型表达能力之间的固有矛盾。

**建议修正**：

```
方案 A（推荐）：使用简单二次形式 (c_C − 0.8)²
  取消 max(0, ·)，让惩罚项对 c_C < 0.8% 的情况产生"奖励"（负贡献）。
  优点：精确可表示为 QUBO（二次函数在二元变量上天然可表示）
  缺点：对低 C 成分产生轻微偏向（可接受——低 C 本身是 favorable 的）

方案 B：C 升至 4 比特
  c_C = 0.25 × (x₀ + 2x₁ + 4x₂ + 8x₃)，范围 [0, 3.75%]
  QUBO 自由度 = 1 + 4 + 6 = 11 > 16 离散值，存在精确表示
  代价：总变量 → 39，耦合数增加（但仍在硬件容量内）

方案 C：使用辅助/松弛变量
  引入 1 个辅助二元变量 s 和额外惩罚项来处理 max
  标准技术但增加 QUBO 复杂度，且需要额外的 penalty 调参

方案 D：接受近似
  使用 QUBO 最小二乘拟合，接受 u=7 时 0.25 的误差
  但需在方案中明确标注近似误差
```

> 📐 **数学注记**：这本质上是一个函数逼近问题——用 3 变量 QUBO（无三体项）去逼近 8 点分段函数。可以证明：3 变量 QUBO 的 basis functions 张成的空间维数为 7，而 8 个任意数据点一般需要 8 维，因此 **对任意给定的 8 点目标值，QUBO 几乎必然无法精确表示**（除非目标值恰好满足隐式约束）。

## 二、v1.5 遗留的未解决问题

### 🔴 遗留缺陷 1（v1.5 缺陷 1）：目标函数量纲不统一——加权和权重被隐性扭曲

**问题定位**：§4.1 三目标设计 + §4.2 加权和聚合

**状态**：❌ 未解决。v1.6 仅对 **惩罚项** 做了归一化（§3.1 S_var/75），但 **目标函数 f₁, f₂, f₃ 本身未做任何归一化处理**。

**重新确认问题**：

| 目标 | 物理量 | 典型数值范围 | 量级跨度 |
|------|--------|-------------|---------|
| f₁ | ΔH_mix (kJ/mol) | −20 ~ +5 | ~25 |
| f₂ | 密度 (g/cm³) | 6.0 ~ 9.0 | ~3 |
| f₃ | 成本（未定义单位）| 未知 | 未知 |

在加权和 `w₁·f₁ + w₂·f₂ + w₃·f₃` 中：
- 即使 w₁ = w₂ = w₃ = 1/3，ΔH_mix 的数值变化（~25 单位）对 QUBO 能量的贡献是密度变化（~3 单位）的约 **8 倍**
- 用户期望的 "50:50 形成能-密度权衡" 实际执行的是 "89:11"
- f₃ 成本指数的单位未定义，其数值范围完全未知——无法预判任何权重组合的实际效果

**量子计算影响**：QUBO 系数矩阵的 spectral radius 由 f₁ 主导。量子退火中 Hamiltonian 的能隙 ΔE₁₀（基态到第一激发态）如果远小于 f₁ 系数的热涨落等效能量，退火器将难以区分 f₂ 和 f₃ 的贡献——它们沦为噪声。

**v1.6 的惩罚项归一化与目标归一化的关系**：

v1.6 的 §3.1 对惩罚项做了 `S_var/75` 归一化，使惩罚项量级 ≈ O(λ_sum)。但目标函数和惩罚项之间的相对比例仍然失调：

```
H_total = [w₁·f₁ + w₂·f₂ + w₃·f₃] + [λ_sum × (S_var' − 1)² + ...]
           ↑ 量级 ~25 (由 f₁ 主导)        ↑ 量级 ~λ_sum
```

如果 λ_sum ≈ 1，惩罚项贡献为 O(1)，目标贡献 O(25)，惩罚太弱 → 约束不满足。
如果 λ_sum ≈ 25，惩罚项贡献为 O(25)，两者平衡 → 但 λ_sum 需从 0.1 自适应增长到 ~25，前几轮迭代约束严重不满足。

**最优实践**：目标函数和惩罚项都应归一化到 O(1)，使 λ_sum 的初始值 0.1 在物理上有意义。

**建议修正**（重申 v1.5 评审建议）：

```
每轮求解前动态归一化（利用已有粗网格信息）：

方案：利用粗网格 6 组求解结果确定目标边界
  f_i^min = min(f_i across all feasible solutions in P)
  f_i^max = max(f_i across all feasible solutions in P)
  f_i^norm = (f_i − f_i^min) / (f_i^max − f_i^min + ε)

或使用物理先验（在粗网格完成前）：
  f₁^norm = f₁ / 30        (ΔH_mix 范围 ~30 kJ/mol)
  f₂^norm = f₂ / 10        (密度范围 ~4 g/cm³)
  f₃^norm = f₃ / c_max     (成本最大值，需预计算)
```

### 🔴 遗留缺陷 2（v1.5 缺陷 2）：加权和法无法恢复非凸 Pareto 前沿

**问题定位**：§4.2.1 理论背景 + §4.2.3 ParetoZoom 算法

**状态**：❌ 未解决。v1.6 未改变多目标标量化方法。ParetoZoom 仍基于加权和标量化 `min Σ w_i f_i(x)`。

**v1.6 的论述变化**：§4.2.6 将 "非凸前沿恢复" 的预期从 v1.5 的模糊描述改为 "依赖粗网格是否覆盖凹陷区方向；6组顶点+边中点提供基础方向多样性"——承认了局限性，但未从根本上解决问题。

**为什么间隙检测无法修复**（重申数学本质）：

加权和法能探索的解集 = {x : ∃w ≥ 0, x = argmin Σ w_i f_i(x)}，这是 Pareto 前沿的 **凸包（convex hull）**。

ParetoZoom 的间隙检测（§4.2.3 第 7-11 行）逻辑：
1. 检测相邻非支配解 (y_i, y_{i+1}) 的距离
2. 距离过大 → 插值新权重 → 重新求解
3. 期望找到中间的解

但在非凸区域：
- 相邻解 (A, D) 距离很大（因为中间的解 B, C 在凹陷处，加权和法解不出来）
- 插值新权重 → 新解仍然落在 A→D 的凸包连线上，**不会落到凹陷区域的 B 或 C**
- 这是一个系统性盲区，迭代轮数增加不会改善

```
        f₂
        ↑
        |   A ●
        |      ╲
        |   B ● ╲   ← 凹陷区的解(加权和法无法到达)
        |      ╱ ╲
        |   C ●   ╲
        |    ╱      ╲
        |   ●────────● D
        |  插值权重     (凸包上的解)
        +──────────────────→ f₁
```

**v1.6 的特殊缓解因素**（为什么这次可能不那么致命）：

v1.6 将 VEC 移出 QUBO 后，QUBO 内部的竞争减少，三目标之间的 trade-off 更"干净"：
- f₁ vs f₂：本质是 Al 含量的权衡（Al↑ → ΔH_mix负↑? 密度↓）→ 接近线性 trade-off → 前沿可能接近凸
- f₁ vs f₃：本质是 Co/Ni 含量的权衡 → 接近线性
- f₂ vs f₃：Al↑ 降低密度但 Co/Ni 是主要成本驱动者 → 不直接冲突

加上 C 的碳化物抑制约束 (c_C ≤ 0.8%) 进一步限制搜索空间 → **三目标前沿可能确实接近凸的**。

**条件性接受**：如果粗网格 6 组求解后，Pareto 前沿经凸性检验（例如检查相邻解的三点共线性），确认其为凸或近似凸，则加权和法可接受。否则必须切换标量化方法。

**建议**：

```
在粗网格阶段完成后，增加"前沿凸性检验"步骤：
  CONVEXITY_TEST(P_0):
    FOR 每三个相邻非支配解 (y_{i-1}, y_i, y_{i+1}):
      判断 y_i 是否在 y_{i-1} 和 y_{i+1} 连线的"外侧"（非凸）
    IF 非凸解占比 > 10%:
      WARNING: 切换为 ε-约束法 或 切比雪夫标量化
    ELSE:
      PROCEED with ParetoZoom
```

## 三、v1.5 遗留的物理/工程问题（持续有效）

### 🟡 遗留问题 1：C 的 ΔH_mix 贡献仍使用正规溶液模型

**问题定位**：§4.1 f₁ ΔH_mix

**状态**：❌ 未解决。公式仍为 `ΔH_mix = 4 Σ_{i<j} ΔH_{ij}^{AB} · c_i · c_j`，C 作为第 6 个"元素"以同样的二次交叉项参与计算。

**v1.6 的缓解**：新增的 P1 碳化物抑制约束 `H_carbide` 会惩罚 c_C > 0.8%，部分抵消 f₁ 对高 C 的偏好。但 **根本问题未解决**——C 参与 ΔH_mix 的物理机制与置换式主元不同，正规溶液模型对间隙元素的适用性存疑。

**后果**：QUBO 内部的竞争矛盾——f₁ 因 C-Cr 强负混合焓而偏好高 C，P1 惩罚高 C，两者在 QUBO 中"拔河"。虽然宏观效果上 P1 可能取胜（限制了 C），但这种对抗降低了 QUBO 能量景观的质量（引入局部极小值），降低量子退火效率。

**建议**：

```
最低干预方案：对 C 的 ΔH 交叉项施加折扣
  ΔH_{i,C}^{eff} = γ · ΔH_{i,C}^{Miedema}, γ = 0.2~0.3
  理由：间隙占位使有效混合焓仅为置换混合的分数
  在方案中标注此处理为近似，并做敏感性分析（γ = 0.1, 0.3, 0.5）

理想方案：从 f₁ 中分离 C
  ΔH_mix = ΔH_mix^substitutional(Al,Co,Cr,Fe,Ni) + ΔH_C^interstitial(c_C)
  其中 ΔH_C^interstitial(c_C) 基于实验溶解焓数据线性近似
```

### 🟡 遗留问题 2：Vegard 定律用于间隙 C 的密度预测

**问题定位**：§4.1 f₂ 密度，ρ_C = 2.27 g/cm³

**状态**：❌ 未解决。C 仍以 ρ_C = 2.27（石墨密度）参与 Vegard 线性混合。

**物理问题重申**：
- 石墨密度 2.27 g/cm³ 反映的是 sp² 层状结构的碳，与 FCC/BCC 晶格中八面体间隙位上的 C 原子毫无关系
- 间隙 C 使晶格膨胀（a ↑），效果与 Vegard 预测方向可能相反
- 1 at% 间隙 C 对 HEA 密度的实际影响量级大约在 ±0.5% 以内（远小于 Al 含量变化的影响）

**实践层面**：由于 C 含量被限制在 ≤1.75%（且 P1 约束进一步限制至 ~0.8%），其对密度的贡献 `0.8% × 2.27 ≈ 0.018 g/cm³` 相比整个合金密度 ~7 g/cm³ 的误差在可接受范围内。**这个问题对最终优化结果的影响较小**，但在方案文档中应明确标注为近似。

**建议**：

```
方案 A：保守近似——f₂ 中忽略 C 的密度贡献
  ρ = Σ_{i∈{Al,Co,Cr,Fe,Ni}} c_i · ρ_i
  误差估计：±0.02 g/cm³ (≪ 0.3%)，远小于其他模型误差来源

方案 B：使用 DFT/实验校准的偏摩尔体积
  标注 "C 密度贡献使用间隙模型校正，非 Vegard 线性混合"
```

### 🟡 遗留问题 3：缺少 HEA 固溶体关键判据 δ 和 Ω

**问题定位**：§7 后处理物理过滤器

**状态**：❌ 未解决。后处理过滤器仍只包含 ΔH_mix、VEC、c_C、c_i > 35%、成分和检查。

**缺失的判据**：

| 判据 | 公式 | 物理意义 | AlCoCrFeNi 等原子比 | 阈值 |
|------|------|---------|-------------------|------|
| 原子尺寸差 δ | δ = √(Σ c_i(1 − r_i/r̄)²) | Hume-Rothery 固溶准则 | ~5.2% | δ < 6.6% |
| Ω 参数 | Ω = T_m·ΔS_mix/|ΔH_mix| | 高熵稳定判据 | ~2-5 | Ω > 1.1 |

δ 的重要性：Al 原子半径 (1.43 Å) 显著大于 3d TM (~1.25-1.28 Å)。f₂（密度最小化）会推高 Al → δ 增大。虽然等原子比 δ ≈ 5.2% < 6.6%，但 Al 升至 25% 时 δ 接近 5.8-6.0%，在边界附近。

Ω 的重要性：f₁ 最小化 ΔH_mix（更负）→ |ΔH_mix| 增大 → Ω 减小。当 Ω < 1.1，混合焓主导，可能形成金属间化合物而非固溶体。这是 **本方案中最隐蔽的物理矛盾**——优化器追求更稳定的相（更负 ΔH），但过负的 ΔH 反而破坏高熵固溶体形成条件。

**建议**：

```
在后处理过滤器 §7 中增加两个检查：

IF δ > 6.6%:
    标记 ⚠️ "原子尺寸差过大(δ={value}%)，固溶体不稳定风险"

IF Ω < 1.1:
    标记 ⚠️ "Ω参数过低({value})，混合焓主导，可能形成金属间化合物"

参数说明：
  T_m = Σ c_i·T_{m,i}  (混合熔点，K)
  ΔS_mix = −R·Σ c_i·ln(c_i)  (理想混合熵)
  |ΔH_mix| = |4 Σ ΔH_{ij} c_i c_j|  (混合焓绝对值)
```

## 六、评审总结

v1.6 体现了对 v1.5 评审意见的认真消化：
- **VEC 移出 QUBO** 是关键的架构决策，消除了物理耦合导致的内部对抗
- **置换式主元 VEC 归一化**（除以 1−c_C）是物理上正确的精细化处理
- **碳化物抑制 P1 约束** 为 C 元素的处理增加了主动的 QUBO 内部引导

但三个关键问题仍在：
1. **目标函数未归一化** — f₁/f₂/f₃ 量级差异导致有效权重扭曲，这是 **进入 QUBO 编码前必须解决的最优先问题**
2. **加权和法非凸前沿局限** — 虽然 v1.6 的"更干净"三目标空间可能使前沿接近凸，但缺乏凸性验证步骤
3. **新增的数学错误**（S_var' 范围）和 **QUBO 表示性问题**（max(0,·)² 不可精确表示）需要在编码前修正

**总体判断**：v1.6 在物理建模上迈出了正确的一步。修正上述 P0 级问题后，方案将具备进入 kaiwu SDK 编码阶段的充分准备。
